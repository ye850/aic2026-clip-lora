# 半决赛 · 500 类细粒度图像分类

> **最终榜分 76.6137** ｜ 团队：明鉴 ｜ 止步于此
> 90,152 张训练图 / 500 类 / 测试 49,857 张

---

## 一、方案

```
图像 ─┬─ CLIP ViT-B/32 视觉塔（官方权重，LoRA 旁路，仅最后 4 层解冻）
      ├─ 池化特征（512 维）── 分类头 512→1024→500 ＋ 可学习 logit_scale
      └─ 推理期：25 视图 TTA → 概率平均 → Sinkhorn 校准 → 提交
```

| 组件 | 配置 |
|---|---|
| **LoRA 微调** | r=16，作用于 `q,k,v,out,fc1,fc2`，仅视觉塔；`unfreeze_last=4` |
| **抗噪损失** | SCE（α=0.1, β=0.05）+ 类别均衡 + mixup 0.2 |
| **平坦极小** | SAM ρ=0.05（强制关 AMP 走 fp32）+ EMA 0.999 + SWA（ep5 起）|
| **蒸馏** | 3 教师软化平均软目标，T=3，λ=0.3 |
| **推理** | 25 视图 TTA + Sinkhorn 校准（iters=15，目标均匀，类计数 SD≈15.3）|

全部超参可从权重的 `args` 里读回。

## 三、这一阶段的核心：11 条判死

11 个机制里 **10 个为负**，唯一为正的不是改模型，而是**多平均 10 个视图**。

完整表格与实测依据见 [`docs/负结果与判死方法.md`](docs/负结果与判死方法.md)。

其中最重要的两条：
- **本地尺子会高估分辨率类收益**（尺子 +0.17 / 榜上 −0.42）
- **训练 val 与榜分已脱钩**（val 最高的模型尺子最低）

## 五、怎么复现

```bash
cd docker
docker build -t aic2026-clip-lora .

# 需要自行准备（不随仓库）：
#   models/clip-vit-base-patch32/   OpenAI 官方 CLIP ViT-B/32
#   models/fd560v2_best.pt          训练权重
#   data/test/                      49,857 张测试图

bash reproduce_submit.sh
```

预期产物 `pred_results.csv`：49,857 行，500 类全覆盖。

> **跨 GPU 复现说明**：同一张卡跑两次 `probs.npy` 的 md5 完全相同（bit 级确定）；
> 换 GPU 型号后 fp16/cuDNN 实现差异会翻转少量"几乎平局"样本（实测抽检 2,001 张，
> argmax 一致率 95.6%，翻转全部集中在 top1−top2 间距 <0.2 的图上，对准确率影响约 ±0.2pp）。
> 细节见 `docs/复现说明.md`。
