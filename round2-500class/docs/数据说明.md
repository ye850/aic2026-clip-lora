# 数据说明

> **数据本身不随本作品提交**（赛题数据由组委会提供，且不应随作品分发）。
> 本文件说明数据的结构、规模与放置方式，便于复现时对齐。

## 一、数据集

| 划分 | 规模 | 结构 |
|---|---:|---|
| 训练集 | **90,152 张 / 500 类** | `data/train/<类别目录>/*.jpg`（目录名以 4 位类 id 开头，如 `0000/`、`0001/`）|
| 测试集 | **49,857 张** | `data/test/*.jpg`（**扁平目录，文件名即提交用 ID**）|

- 图像统一为 **500×500**。
- 类别 id 连续，范围 **0–499**，共 500 类。

## 二、本地评估集（"尺子"）

为在不消耗提交次数的前提下评估模型，我们从训练集中**按类分层留出 4,620 张**：

```
val_ratio    = 0.05
val_per_class= 8        # 每类至少留 8 张
⇒ 实际留出 4,620 张 / 500 类
```

该留出集与训练集**同源同尺寸**，用于计算"尺子分"；经验偏移 **榜分 ≈ 尺子分 − 5.69**。

⚠️ **注意**：本文提交所用权重 `fd560v2_best.pt` 是 `val_ratio=0.0`（**真全量**）训练的，
即它**见过**这 4,620 张。因此**不能**用它在该留出集上评估（会得到训练召回）。
复现时请直接比对最终 `pred_results.csv` 的 md5。

## 四、数据放置（复现时）

数据**不放入镜像、不放入代码包**，由宿主机挂载进容器：

```
宿主机 $AIC_DATA/          →  容器内 /workspace/aic/data/
    ├─ train/              →      train/       （90,152 张，500 类目录）
    └─ test/               →      test/        （49,857 张，扁平）
```

`docker-compose.yml` 已配好该挂载（只读）。若手工起容器：

```bash
docker run --gpus all --ipc=host -it \
  -v /path/to/code:/workspace/aic/code:ro \
  -v /path/to/models:/workspace/aic/models:ro \
  -v /path/to/data:/workspace/aic/data:ro \
  -v /path/to/out:/workspace/out \
  -e AIC_ROOT=/workspace/aic \
  -e AIC_CLIP_DIR=/workspace/aic/models/clip-vit-base-patch32 \
  -e AIC_IMG_SIZE=560 \
  aic-repro:2026-11-01 bash
```

## 五、合规声明

- 本作品**未使用任何外部数据**进行预训练或微调；唯一的预训练权重是 **OpenAI 官方 CLIP ViT-B/32**。
- 赛题测试集**未参与任何形式的训练**（含伪标签反哺、测试时训练）。
- 训练集内做过 **pHash 近似重复清洗**（删除训练集内近似重复图），目的是避免同图跨留出集泄漏，不改变标签语义。
