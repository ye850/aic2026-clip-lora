# 判死的各种方法（负结果清单 · 含实测依据）

> 用途：供复现与评审核对。本作品的核心资产不只是最终模型，而是**用实测把一条条路关掉**的过程。
> 全部数字都是同一把尺子（15 视图 @ 固定 4,620 张留出集）或真实榜分，不是估计。
> 基准：**runA**（640 / 解冻最后 4 层 / 16 轮 / SAM / val 0.05）= 尺子 **81.97**；榜分基准 76.5173 → 最终 **76.6137**。

## 一、今日（2026-11-01）逐条判死

| # | 机制 | 实测 | vs 基准 | 判死依据 |
|---|---|---:|---:|---|
| 1 | **全解冻 12 层（容量）** @560 | 尺子 81.36 | **−0.61** | 容量假设在匹配域下依然无效。复赛阶段同机制为 −1.0，两次独立证伪 |
| 2 | **SCE 剂量 α=0.3**（默认 0.1 的 3 倍）| 尺子 80.71 | **−1.26** | 抗噪损失加剂量反而伤；默认 α=0.1/β=0.05 已在最优点附近 |
| 3 | **LoRA 缩放 ×1.1**（缩放 ckpt 内 `lora_B`）| 尺子 81.75 | **−0.22** | 与本栈既有正则（SAM+mixup+SCE）冲突；10-30 单独测时曾 +0.17，叠加后转负 |
| 4 | **model soup（两种子权重平均）** | 尺子 **78.35** | **−3.62** | 灾难级。不同 seed 落不同损失盆地，直接平均落在盆壁高损失区。**权重平均必须用同一条轨迹上的 checkpoint** |
| 5 | **MixStyle p=0.5** | 训练第 3 轮 val 0.7656（同轮 runA 0.7790）| **−1.3pp** | 同轮次已落后且无收敛迹象，中途终止。该机制原本针对"本地与训练集同源"的捷径，但在已堆 13 个抗过拟合机制的栈上无残余空间 |
| 6 | **多层特征融合 3 层**（-1/-3/-6 层 CLS+patch-mean，投影回 512）| 尺子 79.87 | **−2.10** | 文献 +0.5~2.0 的杠杆在我们的栈上是负的。疑因 LoRA 已重塑最后一层特征，中间层反而引入噪声 |
| 7 | **672 分辨率训练**（12 轮）| 尺子 81.84 | **−0.13** | 训练 val 曾达 0.8173（全场最高），但尺子更低 ⇒ 训练 val 已不能预测尺子 |
| 8 | **672 训练的模型再 FixRes 到 704** | 尺子 81.62 | **−0.35** | 向上 FixRes 对已在高分辨率训练的模型是二次上采样，更差 |
| 9 | **FixRes 560→672（用在冠军上）** | **榜分 76.0959** | **−0.42** | 见下文「最重要的一条」 |
| 10 | **cutmix + CRT + 463 伪标签修正** | **榜分 74.86 / 75.16** | **−1.66 / −1.36** | 重校准后仍大幅落后；该配方家族彻底关闭 |
| 11 | **换种子（seed lottery）** | 尺子 82.01 | +0.04 | 无实质增益，种子噪声在这个量级 |

## 四、最重要的一条：尺子会系统性高估"分辨率类"增益

| 改动 | 尺子 | 榜分 |
|---|---:|---:|
| runA 640 → 672 推理 | **81.97 → 82.14（+0.17）** | —— |
| 冠军 560 → 672 推理 | （val_ratio=0，无法用尺子）| **76.52 → 76.10（−0.42）** |

**原因**：4,620 张留出集与训练集**同源**（同批 500×500 图），而官方测试集是**另一来源**。分辨率上采样的伪影在"同源"数据上几乎无害，在"异源"数据上会被放大。

**推论（已写入流程）**：凡是"推理分辨率"类收益，一律按 1/3 折算或直接不做；只有**降方差**类改动（更多视图、更稳的校准）才真正兑现到榜分。

## 五、方法论层面的三条硬结论

1. **训练时 val 与尺子/榜分已脱钩**：`r672full` 训练 val 0.8173（全场最高）→ 尺子 81.84（低于基准）；`seed2` val 0.8128 → 尺子 82.01。⇒ **只认尺子，不认训练 val**。
2. **权重平均的条件很硬**：必须同一条训练轨迹的不同 checkpoint（线性模式连通），**不能跨 seed**，否则 −3.6pp。
3. **强基线上的"文献增益"要打对折再打对折**：栈里已有 13 个机制（SAM / mixup / SCE / KD / EMA / SWA / class-balance / pHash 清洗 / 软冲突 / 伪标签修正…），任何新机制的残余空间远小于文献报告的"从零加"增益。11 次尝试里 10 次为负，就是这条定律的实证。

## 六、若要重试，需先满足的前提（给后续接手者省时间）

| 被关掉的方法 | 重试前必须先满足 |
|---|---|
| 全解冻 / 加可训练容量 | 先证明当前栈未饱和（现有证据：所有容量型改动为负）|
| 权重平均 / soup | 必须是**同一轨迹**的多 checkpoint；跨 seed 已验证灾难 |
| 分辨率类（FixRes / 高分辨率训练）| 必须先在**异源**小验证集上确认，不能只用同源尺子 |
| 多层特征融合 | 需先用 LoRA 之外的骨干（或冻结骨干）验证该机制本身有效 |
| 换 seed / 换种子集成 | 需先解决"不同 seed 不在同一盆地"的问题 |
