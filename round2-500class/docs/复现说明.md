## 一、复现目标（可逐字节校验）

复现产物应为 **一个 `pred_results.csv`**，其校验值如下：

| 项 | 值 |
|---|---|
| md5 | `506d1919f3654b73e2ebbf9c8530ac90` |
| sha256 | `64086bd6fea918cf65e08c7eaf326121aa98ab92aae8e2763350f951f9e69381` |
| 字节数 | `2,143,851` |
| 行数 | `49,857`（无表头，格式 `文件名, 类别id`）|
| 首行 | `00000e235118438b8cc42f8aa9238488.jpg, 0377` |
| 类别覆盖 | 500 / 500，值域 0–499 |

**判读方式（重要）**

| 情形 | 结论 |
|---|---|
| md5 完全一致 | 复现成功（同一 GPU 型号下必然如此——我们实测同一张卡重跑两次 md5 相同）|
| md5 不一致，但**行数 49,857 / 覆盖 500 类 / 格式正确** | **属正常**，见下 |

**为什么不保证跨卡逐字节一致（实测数据）**

| 层级 | 实测 |
|---|---|
| **同一张 GPU 跑两次** | `probs.npy` 的 md5 **完全相同**（bit 级确定）|
| 逐元素概率差（换 GPU）| 中位数 **1.2e-06**，P90 4.7e-05，P99 1.9e-03 |
| 每张图的最大概率偏移 | 中位数 **1.6e-02**，最大 1.3e-01 |
| argmax 一致率（抽检 2,001 张）| **95.6%**（1,912 张相同、89 张不同）|
| 翻转的分布 | 间距 >0.2 的图 **0 张翻转**；间距 <0.01 的图翻转率 40% |

即：绝大多数概率元素只差 1e-6 量级，但**每张图的最大偏移可达 1e-2 量级**，这足以翻转"几乎平局"的样本。
翻转全部集中在 top1−top2 间距 <0.2 的图上（占 33%），且这些图上新旧预测的概率几乎相等 ⇒
**对准确率的影响约 ±0.2pp**（4.4% 翻转 × 各约 50% 命中率，净变化接近 0）。

因此：**md5 不一致不代表复现失败**；只要行数 49,857、覆盖 500 类、格式正确即属正常。
若需逐字节对齐，请在**与出包机同型号 GPU** 上执行。

## 二、环境（镜像只含这一层）

| 组件 | 版本 | 备注 |
|---|---|---|
| 基础镜像 | `python:3.12-slim` | 镜像内不含 CUDA 工具链，torch wheel 自带 CUDA 运行时 |
| Python | 3.12 | 训练机为 3.12.3 |
| torch / torchvision | **2.6.0 / 0.21.0**（cu124 构建）| PyPI 上 2.6.0 默认即 cu124 |
| transformers | **5.20.2** | 与训练机一致；**不要升到 5.2x 以外的大版本** |
| tokenizers / safetensors / huggingface_hub | 0.23.3 / 0.8.0 / 2.3.0 | transformers 的配套 |
| numpy / pandas / scipy / pillow | 2.1.3 / 3.1.0 / 1.18.1 / 11.0.0 | |
| 宿主机驱动 | NVIDIA 560.35.03（CUDA 12.6）| 仅需驱动，容器内不需要完整 CUDA toolkit |

> **镜像内刻意不装**：`scikit-learn`、`timm`、`einops`、`opencv` —— 对 `src/*.py` 与
> `scripts/*.py` 做全量 import 扫描，确认一行都没用到，装上是纯浪费体积。

### ⚠️ 一处必须注意的环境不一致（我们主动披露）

本项目早期版本曾用过 **torch 2.12.1+cu130** 的环境（对应更早一版分数）。**本次提交包（76.6137）
实际是在 torch 2.6.0+cu124 上产出并出包的**，因此镜像与 `requirements.image.txt` 一律按 **2.6.0+cu124** 锁定。
若改用 cu130 或其他大版本，transformers/torch 的 tokenizer 与位置编码插值行为可能漂移，**预测不保证一致**。

> **关于 `--workers`**：示例统一用 `--workers 0`（单进程）。在 Windows Docker 或 `/dev/shm`
> 受限的容器里，多进程会报 `DataLoader worker exited unexpectedly`（我们实测 workers=4/8 均崩，
> 加 `--ipc=host` 也未能完全解决）。Linux 服务器上可改 `--workers 8` 提速，**结果不受影响**。

## 四、复现命令（三步，全部确定性）

```bash
# 0) 起环境
docker compose up -d
docker compose exec aic-repro bash

# 1) 25 视图 TTA 推理（560 原生分辨率，不加任何分辨率补丁）
cd /workspace/aic/code
python scripts/predict_tta.py \
  --lora /workspace/aic/models/fd560v2_best.pt \
  --views base,flip,zoom240,zoom256,zoom288,zoom288f,zoom320,zoom336,square,rc0,rc1,rc2,rc3,rc4,rc5,rc6,rc7,rc8,rc9,rc10,rc11,rc12,rc13,rc14,rc15 \
  --out-dir /workspace/out/_tta --save-probs /workspace/out/_tta/probs \
  --force --workers 0

# 2) 概率校准（Sinkhorn，目标类分布均匀，15 次迭代）
python scripts/calib_sinkhorn_apply.py \
  --probs /workspace/out/_tta/probs.npy \
  --out-dir /workspace/out/pack \
  --target uniform --iters 15 --force

# 3) 校验（行数/类覆盖/SD）
python scripts/check_submission.py /workspace/out/pack/pred_results.zip
md5sum /workspace/out/pack/pred_results.csv     # 应为 506d1919f3654b73e2ebbf9c8530ac90
```

**单卡 A100 / 4090 上第 1 步约 75 分钟**（25 视图 × 49,857 张，560 分辨率）。

## 五、复现边界（如实说明，避免误判）

1. **CLIP 权重来源**：仅使用 OpenAI 官方 `openai/clip-vit-base-patch32`，未做任何自监督预训练或外部数据预训练；LoRA 与分类头均为本赛题数据上训练。
2. **确定性**：TTA 视图顺序、文件遍历顺序、Sinkhorn 迭代次数均为固定值，无数值随机性（`torch.no_grad()` 推理，未开 dropout）。
3. **GPU 架构差异**：若复现机器不是 A100/4090，cuDNN 卷积算法选择可能不同，浮点结果可能有 1e-6 级差异；**argmax 结论应一致**（我们在 A100 与 4090 上交叉验证过同一权重给出同一份 `pred_results.csv`）。
4. **不做任何提交端集成**：单模型 + 单次 TTA + 单次校准，无多模型融合、无测试时训练、无伪标签反哺测试集。
