# AIC 2026 算法挑战赛道 · 两阶段参赛记录

> **团队：明鉴** ｜ 全程只允许使用 OpenAI 官方 CLIP ViT-B/32
> **复赛 77.7241**（750 类）→ **半决赛 76.6137**（500 类）→ 止步半决赛

这里是我们两个阶段的完整记录：方法、实验、以及**被实测关闭的技术路线**。
主体不是"我们赢了多少"，而是**把哪些看似合理的路逐一测死、依据是什么**。

<sub>English TL;DR: Two stages of a CLIP ViT-B/32 fine-tuning competition, restricted to OpenAI's official weights. Round 1 (750 classes, ~33% label noise) scored 77.72; round 2 (500 classes) scored 76.61. This repo's core value is **the negative results with measured numbers** — most techniques we tried made things worse, and the only positive change in round 2 came from variance reduction (15 → 25 TTA views), not from a stronger model.</sub>

## 一、两个阶段

| | 复赛 | 半决赛 |
|---|---|---|
| 目录 | [`round1-750class/`](round1-750class/) | [`round2-500class/`](round2-500class/) |
| 类别数 | **750** | **500** |
| 训练量 | 148,695 张，噪声率 ~33% | 90,152 张 |
| 分辨率 | 448 | 560 |
| **榜分** | **77.7241** | **76.6137** |
| 核心难点 | 标签噪声（33%）| 细粒度 + 训练/测试不同源 |
| 主要手段 | 冻结特征 + 轻头 + SCE + 类平衡 + 冲突组软目标 | LoRA + SAM + KD + 25 视图 TTA + Sinkhorn |

两个阶段是**两条不同的技术路线**，不是简单加码：
复赛把算力花在**方法迭代**上（冻结特征 + 轻头，一轮能跑几十个对照）；
半决赛转成**端到端微调 + 推理期降方差**。

## 三、三个关键发现（换任何比赛都成立）

### 1. 本地验证集有系统性偏差，会高估"分辨率类"收益

| 改动 | 本地尺子 | 榜分 |
|---|---:|---:|
| 640 → 672 推理（基线模型）| 81.97 → **82.14（+0.17）** | —— |
| 560 → 672 推理（冠军模型）| （真全量，无法上尺子）| 76.52 → **76.10（−0.42）** |

本地 4,620 张留出集与训练集**同源**，官方测试集**异源**。上采样伪影在同源数据上几乎无害，在异源上被放大。
⇒ **分辨率类收益必须按 1/3 折算或直接不做；只有降方差类改动才兑现到榜分。**

### 2. 训练时验证准确率与榜分已脱钩

| 模型 | 训练 val | 本地尺子 |
|---|---:|---:|
| r672full | **0.8173（最高）** | 81.84（最低）|
| runA | 0.8156 | 81.97 |
| seed2 | 0.8128 | 82.01 |

**训练 val 最高的模型，尺子反而最低。只认本地尺子，不认训练 val。**

### 3. 权重平均有硬前提

两个独立训练、各自尺子 82.14 / 82.01 的模型，直接平均权重后掉到 **78.35（−3.62pp）**。
原因：换随机种子后落在**不同损失盆地**，平均落在盆壁高损失区。
⇒ **model soup 必须用同一条训练轨迹上的 checkpoint，不能跨 seed。**

## 四、半决赛：11 条被实测关闭的路线

基准：`runA`（640 / 解冻 4 层 / 16 轮 / SAM）= 本地尺子 **81.97**。

| # | 机制 | 实测 | 相对基准 |
|---|---|---:|---:|
| 1 | 全解冻 12 层（容量）| 尺子 81.36 | **−0.61** |
| 2 | SCE 剂量 α=0.3（3×）| 尺子 80.71 | **−1.26** |
| 3 | LoRA 缩放 ×1.1 | 尺子 81.75 | −0.22 |
| 4 | model soup（跨 seed）| 尺子 **78.35** | **−3.62** |
| 5 | MixStyle p=0.5 | 同步第 3 轮 val 落后 1.3pp | 中途终止 |
| 6 | 多层特征融合 3 层 | 尺子 79.87 | **−2.10** |
| 7 | 672 分辨率训练 | 尺子 81.84 | −0.13 |
| 8 | r672 再 FixRes 到 704 | 尺子 81.62 | −0.35 |
| 9 | **FixRes 560→672** | **榜 76.0959** | **−0.42** |
| 10 | cutmix + CRT + 伪标签修正 | **榜 74.86 / 75.16** | **−1.66 / −1.36** |
| 11 | 换随机种子 | 尺子 82.01 | +0.04（无实质增益）|
| ✅ | **TTA 视图 15 → 25** | **榜 +0.096** | **唯一为正** |

更早阶段还关闭了：秩加倍 r32（−1.41）、VPT（−1.27）、cosine margin（−2.0）、标签调整 la（全负）、强增广（负）、类均衡重采样（负）、ASAM（负）。

完整依据见 [`round2-500class/docs/负结果与判死方法.md`](round2-500class/docs/负结果与判死方法.md)。

## 五、复赛：判死审计

复赛阶段留下 **85 份实验记录**，其中多份是成体系的判死审计。最典型的三类：

| 方向 | 判死依据 |
|---|---|
| 标签修正 / 带权标签修正 | 自划验证提升，榜分不动甚至下降 |
| 域差归一化类改动 | 三类独立判据全部不通过 |
| 筛样本 / 减训练集 | 非循环判据下不可行 |

反复出现的教训写在 `round1-750class/experiments/更正_*.md` 里：
**同一机制在不同切分上测出的符号会相反**——本项目栽过两次，之后定下规矩：所有数字必须标注"测在什么切分上"。

## 八、我们没做到的

**这是这个仓库里最真实的一节。**

1. **止步半决赛**。半决赛榜分 76.6137，比榜首低约 3.5pp。差距不在调参，在**方向选择**——我们把精力花在一条成熟路上拧旋钮，而没有去找那条没走过的路。
2. **"11 次里 10 次为负"被我误读成了"栈已饱和，所以只认降方差"**。现在回头看，它更可能是在说"这条路到头了"。这个判断错误是最大的收获，也是最贵的。
3. **多层特征融合没跑完**（只到 8 轮，尺子 79.87），无法区分"机制无效"还是"轮数不够"。
4. **真全量模型不可测量**：半决赛冠军权重用 `val_ratio=0` 训练，无法再用本地尺子评估，只能靠榜分反馈。
