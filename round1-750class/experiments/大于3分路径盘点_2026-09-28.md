# 「哪条路可能有 >3pp 提分空间」盘点（2026-09-28）

> 用户前置：**复赛占线上综合成绩 40%（已写死）** ⇒ 复赛 +3pp = 综合 +1.2pp。
> 本文只回答一件事：**哪条路"可能"给出 >3pp**。凡推断标「推断」，凡实测标出处。

---

## 零、一句话答案

**有。不是一条旋钮，是一整片我们几乎没动过的区域：训练侧的正则 / 增强面。**

理由是它同时满足三个条件，而其它所有候选都不满足：

1. **有一片"从未被打开过"的空间** —— 几何增强**只有 crop(0.7~1.0) + 水平翻转**，
   标签平滑**接线好了但值是 0.0**，EMA **只用于出包、没当教师**。这不是"试过发现没用"，
   是**从来没打开过**（见 §一 / §二）。
   ⚠️ 我原本还想用「所有臂 `best_ep` 都落在 6~10 / 12 ⇒ 正则不足」来支撑这条路 ——
   **这个推论已被当晚 CE 读数推翻，见 §六。方向要重定。**
2. **是组合式的** —— 单项 0.5~1.5pp 级的组件有 5~6 个，**叠加才可能过 3pp**。
   单旋钮（τ、seed、TTA、解冻）已经是 0.1~0.9pp 级、基本吃完了。
3. **有一条"我们主动锁死了它"的硬证据**（见 §二）—— 不是"没试过"，是**当年用错误的成本判断把它排除掉的**。

## 一、这片区域现在到底有多空（逐项实测核实）

`src/finetune_lora.py:_build_tf()`（195~229 行）**逐行读完**，训练增强的全部内容就是：

```
[可选 degrade]  →  RandomResizedCrop(448, scale=(0.7,1.0))  →  RandomHorizontalFlip(p=0.5)
                   [仅当 --aug strong] + 高斯模糊(p0.3) + ColorJitter + 灰度(p0.02)
[仅当 --aug strong]
```

| 组件 | **我们现在的状态** | 线索 / 依据 |
|---|---|---|
| **几何增强** | **只有 `RandomResizedCrop(0.7~1.0)` + `HFlip` —— 就这两个** | 代码注释明写「**几何一律不动**」（见 §二） |
| 强增强 | 只有 `plain` / `strong` 两个选项（`--aug` choices） | `--aug strong` **从未在 q75 尺上评过**（误杀候选） |
| 成像退化 | `degrade = None`（冠军配方） | `--degrade` 已证：干净尺 **−0.73pp**(p=.013) → **q75 尺 +0.61pp**(p=.052)，符号翻转；榜分 `deg_balU` 73.52 > 73.26 |
| **标签平滑** | **`config.py:281 LABEL_SMOOTH = 0.0`** | ★ **接线是好的、只是没打开**：`noise.py:330` 已把它传给 CE 的 `label_smoothing` ⇒ **改一个常量即可启用，零代码改动** |
| mixup | 恒 **0.2** | 只在 **224 时代的 Round-4** 扫过 0.5（`queue_round4.sh:"mx5\|--mixup 0.5"`）；而 R2/3/4 全部漏设 `AIC_IMG_SIZE` ⇒ **448 上从未扫过** |
| **EMA 当教师** | **不存在** | 全程有 EMA（`ema_decay .999`），但 **只用于评估/出包**；今晚的 drift 臂用的是 `deepcopy(model)`（**未微调初始副本**）⇒ 是"防漂移"，**不是** Mean Teacher 的"EMA 学生当教师" |
| dropout / WD | 0.1 / 1e-4（冠军） | 未见扫描记录 |

## 二、★ 最关键的一条：我们为了一个噪声级收益，锁死了整个强增强面

`src/finetune_lora.py:215-218` 原文注释：

> ⚠️ **几何一律不动**（仍是 scale=0.7~1.0 + hflip）。理由：TTA 的 `rc0..rc15` 视图被刻意定义成
> "与训练分布逐字一致"，一旦放宽 scale，那 16 个视图立刻变成"分布外视图"，前面所有 TTA 结论
> 全部作废。**改几何的代价远大于收益。**

**这个成本-收益判断是错的**，因为收益那一侧已经被量过：

- `predict_tta.py` 头部注释实测：**15 视图相对 8 视图 Δ全体 +0.0044**（那还是"视图集之间"的对比）；
- `outputs/_final_augstrong/eval_val.log` / `_final_r320plain/eval_val.log` 里的**视图增删配对检验**：
  `base+flip` Δacc **+0.0028**(p=0.080) / **+0.0008**(p=0.695)，`-rc5`、`-zoom240` 一档
  **±0.0012~0.0023** —— 全部**低于**该表自己写的「全体 acc 标准误约 **0.0055**」。

⇒ **TTA 视图增删这一整套结论，本身就落在噪声内。**
⇒ 用"保住一批噪声级结论"，换掉**细粒度任务上最标准的强增强**（RandAugment 族），
   **这是本项目最大的一次「为了保住旧结论而放弃新空间」**。

⚠️ 边界（必须说清）：放开几何增强会**重置** `rc0..rc15` 那套视图结论，需要重新定 TTA 口径。
但被重置的东西幅度是 **0.002 级**，重置成本极低。

## 三、为什么"可能 >3pp"（不是空想，有量到的东西撑着）

1. **模型对画质退化没有免疫力，且已被量化**：`finetune_lora.py:210` 注释引 `quality_drop.json`：
   「把 val 压到 500+JPEG 就掉 **1.96 分**」。
2. **注入退化确实有效，且符号会翻**：`--degrade` 干净尺 −0.73pp → q75 尺 **+0.61pp**
   ⇒ **训练分布对齐**这一维是真实的、之前的读数是被尺子压负的。
3. **细粒度识别的文献共识**：强几何增强（RandAugment / TrivialAugment）在细粒度分类上
   是 **+1~3pp 级**组件 —— 而我们对几何增强**只有 crop + flip**。
4. **是组合，不是单点**：几何增强 + 退化注入 + 标签平滑 + mixup 扫参 + EMA 教师，
   每项 0.5~1.5pp（**推断**）⇒ **叠加过 3pp 是可能的**。
5. **合规无风险**：全部落在「CLIP ViT-B/32 + 官方权重 + 单一模型 + 单一推理流程 + 只用训练数据」内，
   不碰测试集、不做集成 ⇒ ✅ 不触任何红线。

## 五、诚实边界（不许把它讲成承诺）

- 这些**都是"可能"，不是"已验证"**。单项量级 **0.5~1.5pp**；
  **没有任何一条我能保证 +3pp**。
- 组合叠加的假设前提是"各组件作用方向独立" —— 在强正则场景下**不总成立**（可能互相挤占）。
- 但反过来：**这是目前唯一一片能让多个 0.5~1.5pp 组件叠加的区域**。
  单旋钮（τ / seed / TTA / 解冻 / sel-frac / 伪标签）已经全部是 0.1~0.9pp 级、且大多吃完或判死。
- 已知的最大单轴：均衡校正 **+0.94pp**（已吃）、成像协议 **1.51pp**（上限，未吃满）。
- 战略提醒：**半决赛占 60%**。若目标是"综合 80"，而半决赛也是 80，则复赛需 80；
  若半决赛只到 X，则复赛需 `(80 − 0.6X)/0.4`。⇒ **这 60% 比复赛的 40% 更值得留资源。**

## 六、★ 自我修正（09-28 当晚 CE 读数，写本文时同步到的）

写上面 §零 时我用了「所有臂 `best_ep` 落 6~10/12 ⇒ 正则不足」。**当天 CE 臂的逐轮读数把这个推论推翻了。**

| 轮 | val_acc（EMA） | 低相似 `lowsim_a` | **raw（裸权重）** |
|---|---|---|---|
| ep4 | 0.7600 | 0.6333 | 0.7263 |
| ep5 | **0.7661** | 0.6370 | 0.7373 |
| ep6 | 0.7654 | 0.6366 | 0.7394 |
| ep7 | 0.7632 | 0.6310 | 0.7471 |
| ep8 | 0.7645 | 0.6370 | 0.7522 |
| **ep9** | 0.7660 | **0.6400（新高）** | **0.7581** |

两个事实：
1. **val_acc 在 ep5~ep9 基本是平的**（±0.15pp 波动），但**低相似子集 ep9 才创新高**、
   **裸权重单调上升**（每轮约 +0.006）⇒ **裸 CE 配方下训练还没收敛**。
2. 而冠军（`ul4`，SCE+CL）的 `best_ep=6`，ep6 之后就走低。

⇒ **结论（要修正的）**：**"`best_ep` 不在最后一轮"是弱判据** —— val 在 ±0.15pp 抖动时，
   "取最大值的那一轮"本来就会散开，它**不能**单独证明过拟合。
   ⇒ 更可能的真相是：**最优轮数与 `loss` 强相关**（SCE+CL 早熟、裸 CE 晚熟），
   而不是"正则整体不足"。

**由此产生的两个动作**：

1. ★★ **`epochs 18` 的判死也要列入待复核**（第 5 条）。它当年的依据正是「`best_ep` 不贴边」，
   而这正是被上面推翻的那个弱判据；且它是在**冠军配方**下做的，**不可外推到裸 CE / 换 loss**。
2. ⚠️ **方向层面出现"两个相反的可能"**，现有证据**不能裁决**：
   - **A 加正则**（强增强 + 标签平滑 + EMA 教师）→ 若真相是"过拟合"
   - **B 加轮数 / 减弱已启用的正则** → 若真相是"还没收敛"
   ⇒ 这也是为什么 §四 的 **第 0 步（误差分解，¥0）必须放在前面**：
   不先量出"错在哪、训练是否真在过拟合"，A/B 就是在赌。

**这段话不推翻的事实**（仍然成立）：
- 几何增强**只有 crop+flip** ⇒ **确实是空白**；
- 标签平滑**确实是 0.0**（接线已好）；
- 「为保 TTA 口径而锁定几何」的**成本判断确实是错的**（视图增删 < SE）；
- `--degrade` **确实有效**（q75 尺 +0.61pp、榜分不吃亏）。
⇒ 只是"**该往哪个方向补**"从"确定"降级为"**需要先诊断**"。
