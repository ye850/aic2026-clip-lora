# 带权标签修正 —— 实测判死（2026-10-04）

> 用户 10-04 提出的新大方向：「**让模型识别并降低错误标签的影响**，先用冻结的官方
> CLIP 特征，结合**近邻类别一致性**、增强视图一致性、有语义时的图文相似度，给训练样本
> 估一个可信度；对可疑标签做**软修正或降权**，避免简单删样本。」
>
> 其中「近邻类别一致性」是**唯一可以不依赖类名就实现**的支柱（图文相似度需类名）。
> 本文件记录它的**实测结果**，结论是**判死**，且给出了**结构性原因**（不只是"没效果"）。

---

## 一、为什么先测这一条

用户判断「差距在**噪声标签处理**，不在缓存尺寸」，并指出
**细粒度噪声标签研究里的「带权标签修正」不同于普通 `SupCon`**，
所以 `d_r448supcon` 没涨**不能**说明这条路线无效 —— 这个论证是对的，
本条确实是本项目**唯一"从未测过、且原理独立"**的方向：

| 已判死的方向 | 判死理由 | 与本条的区别 |
|---|---|---|
| `SupCon` | 在**训练域内**提升分辨力 | 本条**改标签本身** |
| `SCE` / `GCE` | 只是**降权难样本**，不改标签 | 本条要**识别哪些标签是错的** |
| `hardw` | 给难样本加权 ⇒ **等于给污染加权** | 本条是**反向**：给疑似污染**减权** |
| 近重复簇纠标 | 近重复只覆盖 **5.2%** 样本 | 本条用**全量近邻**，覆盖面 100% |

⇒ **值得实测**。而且它便宜：纯 CPU、~1 分钟、不动云端 GPU。

## 二、探针设计（`scripts/_probe_label_trust.py`）

避开前几次测量的坑（铁律 6ac / 6ad）：

1. **报每类张数**：全体 148,695 / 750 类，中位 **196**、min 5、max 248；
   抽样 query 30,000，每类中位 40（**<50 的类有 649 个** ⇒ 已标注，不作类心用）。
2. **OOF 概率天然无自泄漏**：`src/train_head.py:186` 的 `get_oof_probs` 是
   `StratifiedKFold` 分层 K 折，`oof[va] = probs` ⇒ **验证折从未参与该折训练**
   ⇒ `s_own = p_i[标签 i]` **本身就是留一估计，不需要再手写 LOO**。
   （这一点已回源码核实，不是推断。）
3. **近邻共识用 k=20**（不是 k=1）：账本单近邻 top-1 只有 **9.8%** ⇒ 单票是弱信号，
   但 20 个近邻的**共识分布**先验上应该很纯 —— **本探针第一件事就是量这个纯度**。
4. **必须有对照**：在 750 类上"最近邻落在别类"本来就该是 749/750 ≈ 99.9%，
   而实测 41% 看着很大 —— 但那可能是细粒度锥效应，不是噪声
   （`label_noise_val.log` 已经自己反省过这一条，并发现该指标**不单调**）。

## 三、实测结果

### 3.1 近邻共识占比本身极低

| 量 | 读数 |
|---|---|
| top-1 近邻类 == 标签 | **0.0982** |
| 20 近邻共识占比 `c_knn` 均值 | **0.0629** |
| `c_knn` 分位 | p25 = 0.0000、**p50 = 0.0500**、p75 = 0.10、p95 = 0.20、p99 = 0.30 |

⇒ **中位样本的 20 个近邻里，只有 1 个跟它同类。** 这不是"个别样本标签错"，
而是**近邻结构整体在 750 类细粒度上没有兑现**（与账本 kNN 10.0% 完全一致，
两条独立路径互相印证 ⇒ **读数可信**）。

### 3.2 ★ 决定性分层：按 `c_knn` 分层后，`s_own` 几乎不动

| 分层 | n | 占比 | `s_own` 均值 | 与其余之差 |
|---|---|---|---|---|
| `c_knn` < 0.05 | 12,739 | 42.46% | **0.7088** | +0.0010 |
| `c_knn` < 0.10 | 20,010 | 66.70% | **0.7082** | −0.0000 |
| `c_knn` < 0.20 | 27,222 | 90.74% | **0.7094** | +0.0127 |
| `c_knn` < 0.40 | 29,920 | 99.73% | **0.7082** | −0.0092 |

**四档极差 = 0.0012。** 若近邻共识真能识别错标，低共识组的 `s_own` 应显著更低。
**它没有。**

三个信号两两相关（Pearson，n=30,000）：

| 对 | 相关 |
|---|---|
| `s_own` ~ `c_knn` | **−0.0050** |
| `s_own` ~ `s_top1` | **−0.0057** |
| `c_knn` ~ `s_top1` | +0.1480 |

⇒ `s_own` 与两个近邻信号**近乎完全独立（|r| < 0.006）**。

**判定：`SIGNAL_WEAK`**（判据：需 Δ > 0.15 才算活）。

## 四、★★★ 结构性原因（这才是判死的硬理由，不是"没效果"）

"没效果"可以是探针不够好。但下面这条是**数学上跑不通**：

| 分组 | n | `s_own` 均值 | top-1 置信度 |
|---|---|---|---|
| `argmax == 标签` | 22,228 | **0.9305** | 0.9305 |
| `argmax != 标签` | 7,772 | **0.0725** | 0.6087 |

| 条件 | 张数 | 占比 |
|---|---|---|
| 预测错 **且** `s_own` > 0.5 | **0** | 0.00% |
| 预测错 **且** `s_own` > 0.9 | **0** | 0.00% |
| 预测错 **且** `s_own` > 0.99 | **0** | 0.00% |

### 为什么必然是 0

`s_own ≡ P(标签)`，而模型的**输出决策**是 `argmax`。两者被同一个 `argmax` 绑死：

> **只要 `argmax` 不是标签，`s_own` 就不可能大。**
> 要 `s_own > 0.5`，就必须有 >50% 的概率质量落在标签那一维上，
> 那 `argmax` **必然**就是标签。**逻辑上互斥。**

⇒ `s_own` 里**不含**任何"模型知道但输出没选"的信息。
它是一个**被 `argmax` 折叠掉的信号** —— 只能区分"模型答对了"和"模型答错了"，
**无法区分**「模型答错，因为图难」与「模型答错，因为标签本身错」。

### 想用它分辨错标，只剩一条路 —— 但它算不出量

| 情形 | `s_own` | top-1 置信度 | 混杂？ |
|---|---|---|---|
| 预测**对** | 高 | 高 | — |
| 预测**错** + 干净标签（真难） | 低 | **低~中** | 与下一条**无差异** |
| 预测**错** + 标签错（本应预测"错"的那类） | 低 | 应当**高**（模型很确信） | 无差异 |

理论上：**"预测错" 且 "模型很确信" ⇒ 疑似错标**。
实测**零张落在该格**，因为 `s_own` 高 = 预测对，两者互斥；
唯一独立量是 top-1 置信度，但它**同时**被"真难样本"占据，**无法分离**。

⇒ **近邻共识这条支柱，在数学上就无法兑现"识别错标"这件事。**

## 五、那"真难样本"到底占多少（顺带回答了用户的一个怀疑）

「真难」vs「错标」无法分离，但**它们的总量**可以量：

| 量 | 读数 |
|---|---|
| OOF top-1 正确率（n=30,000） | **0.7409** |
| 错分样本 `rank(标签)` 中位 | **5.0** |
| 错分样本中 `rank ≤ 5` 占比 | **53.0%** |
| 错分样本中 `rank ≤ 10` 占比 | **65.6%** |

⇒ **错分样本里，真标签有 66% 就在 top-10 之内** —— 模型"知道"，只是没选对。
这与铁律"**瓶颈＝真·类间视觉重叠，缺的是'选对'**"完全一致。

★ 关键推论：**"错标"与"真难"在这个数据上产生的是同一个签名**
（都是"标签不在 top-1，但常在前几"）。
⇒ 任何**只靠特征/概率的自动方法**都无法把两者分开
⇒ **想分开就必须引入外部语义（类名 → 图文相似度）**。

## 六、结论与操作含义

| 判定 | 依据 |
|---|---|
| 🛑 **「近邻类别一致性 → 可信度 → 带权标签修正」判死** | `s_own` 与 `c_knn` 独立（r=−0.005）；四档极差 0.0012 |
| 🛑 **结构性不可行**（比"没效果"更强） | `s_own` 与 `argmax` 逻辑互斥 ⇒ "错且确信"格恒为空 |
| ⚠️ **"软修正/降权"失去依据** | 无法给出可信度 ⇒ 权重无从设；且 `hardw` 已证明"抬难＝给污染加权"，反向的"减权"缺真值 |
| 🔓 **剩下的唯一出路＝引入类名**（图文相似度） | 只有外部语义能把"错标"与"真难"分开 ⇒ **但这条要问组委会**（是否算"引入额外数据集"） |

### 连带影响：用户新方向的三个支柱现状

| 支柱 | 现状 |
|---|---|
| **近邻类别一致性** | 🛑 **本轮实测判死**（信号弱 + 结构性不可行） |
| 增强视图一致性 | ⚠️ 与近邻同源（都是"同一图的不同视图→同标签"）⇒ 预期同样弱；**未单独测** |
| **图文相似度** | 🔓 **原理上唯一可行**，但**依赖类名** ⇒ 卡在规则确认 |

⇒ **用户新方向的"自动噪声识别"部分，在无类名条件下已判死。**

## 七、我没有做的（诚实标注）

1. **没有跑增强视图一致性**：它与近邻一致性同属"视图/近邻自洽"族，
   本轮既然该族被结构性判死，单独跑价值低；但**严格说它是另一条测量**，未测就是未测。
2. **没有做"软修正后重训"的端到端**：既然可信度信号不存在，端到端必然无效，
   所以省掉了这次 ~100min × ¥4.5 的云端开销 —— 这是**有意的取舍**，不是遗漏。
3. **`s_top1`（top-1 近邻相似度）没做分层展示**：它的 p50 = 0.9173 且与 `s_own` 相关 −0.006，
   信息量与 `c_knn` 重合，未单列。
4. 所有读数基于 **30,000 抽样**（种子 20261004）与**冻结 CLIP 特征**；
   换成 LoRA 微调后的特征可能不同 —— 但**结构性那条（`s_own` ⊥ 错标）与特征无关**。
