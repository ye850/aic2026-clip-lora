## 3. 完整复现步骤（三步）

### 第 0 步：预处理缓存（只需一次，≈20 min）

```bash
export AIC_IMG_SIZE=448
PYTHONPATH=src python scripts/build_preproc_cache.py \
    --procs 8 --short 320 --long-cap 640 --quality 92
    # 默认 --out = data/_preproc/train
```

> 训练时用 `--preproc` 即从 `data/_preproc/train` 读（该路径在代码里是**硬编码**的），
> 单轮从 ~25 min 降到 ~6.7 min。
>
> ★★ **这个缓存会轻微改变训练分布，必须有意识地复现**：
> 裁剪范围 `scale=(0.7,1.0)` 不变，但**源分辨率从短边 ~589 降到 320**
> ⇒ 从 320 里裁 70% 得 224、缩放比 1.0（缓存版图**更锐**）。
> ⇒ **绝对分数不可与"不用缓存"的旧结果横比**；因此本方案**固定使用 `--short 320`**，
> 复现时请保持该值一致。

### 第 1 步：训练（≈100 min / 4090）

```bash
export AIC_IMG_SIZE=448
export OMP_NUM_THREADS=8

python -u scripts/arm_runner.py -- \
    --epochs 12 --batch 96 --workers 8 --lr 2e-4 --head-lr-mult 5 \
    --targets q,k,v,out,fc1,fc2 --dropout 0.1 --mixup 0.2 \
    --ema-decay 0.999 --ema-start 1 --unfreeze-last 4 \
    --preproc --track-lowsim --select-by lowsim_a --log-every 200 \
    --hidden 1024 --r 16 \
    --ckpt outputs/d_r448mlp1024/lora.pt --out-dir outputs/d_r448mlp1024
```

**逐参数说明（这一组就是 74.3 的配方）**

| 参数 | 值 | 说明 |
|---|---|---|
| `--epochs` / `--batch` | 12 / 96 | |
| `--lr` / `--head-lr-mult` | 2e-4 / 5 | 分类头学习率 = 主干 × 5 |
| `--unfreeze-last` | 4 | 解冻**最后 4 层全参数**（ViT-B/32 上 ≈30.7 M，占主干 34.9%） |
| `--targets` | q,k,v,out,fc1,fc2 | LoRA 注入位置 |
| `--r` | 16 | LoRA 秩 |
| **`--hidden`** | **1024** | **分类头 = 两层 MLP（默认 0 = 单层线性）** ★ 相对线性头 +1.04pp |
| `--dropout` / `--mixup` | 0.1 / 0.2 | |
| `--ema-decay` / `--ema-start` | 0.999 / 1 | 评估用 EMA 权重 |
| `--preproc` | — | 读 320 缓存（训练仍需按 448 重采样） |
| `--track-lowsim` + `--select-by lowsim_a` | — | 按"低相似子集"选最优 epoch（防本地虚高） |
| **`--kind`** | **`sce_legacy`** | ⚠️⚠️ **复现本包必须显式写这一条**（默认已改为标准 SCE）。<br>`sce_legacy` = **历史实现**：其 RCE 项为 `−Σ p log p`（**预测熵，不含标签**），**不是** Wang et al. 2019 的标准 SCE（应为 `−Σ p log y`）。<br>★ **榜分 74.3 就是用 `sce_legacy` 训出来的。**<br>★ 2026-10-05 起 `--kind sce` 已改为**标准 SCE**（与官方实现逐位一致），**不再是本包的配方**。<br>详见 `outputs/SCE实现错误_复核与后果_20261005.md` |

> ★ 用 `scripts/arm_runner.py` 包装是**刻意**的：它支持"进程内 patch、不改源码"，
> 与 `finetune_lora.py` 走同一条 `main()` 路径（`sys.argv` 转交）。
> 直接调 `finetune_lora.py` 并传同样的参数**等价**。

产出：`outputs/d_r448mlp1024/lora_best.pt`（训练日志会打印
`[model]` 结构自证与 `最优 epoch / val_acc` 供核对）。

### 第 2 步：出包（15 视图 TTA + Sinkhorn 均衡校正，≈25 min）

```bash
export AIC_IMG_SIZE=448

# ②-1 多视图推理并融合（power 平均，t=4），同时落盘概率供校正用
python -u scripts/predict_tta.py \
    --lora outputs/d_r448mlp1024/lora_best.pt \
    --views best --fusion power --fusion-t 4 \
    --out-dir outputs/_r448mlp1024_pack \
    --save-probs outputs/cache/probs_test_d_r448mlp1024 \
    --force

# ②-2 Sinkhorn 均衡校正（CPU，纯后处理）→ 出提交 zip
python -u scripts/calib_sinkhorn_apply.py \
    --probs outputs/cache/probs_test_d_r448mlp1024.npy \
    --out-dir outputs/submission_d_r448mlp1024_balU \
    --target uniform --force
```

**`--views best` 展开为下列 15 个视图**（`scripts/tta_lora_eval.py::DEFAULT_VIEWS`，逐字）：

```
base, flip,
rc0, rc1, rc2, rc3, rc4, rc5, rc6, rc7,
zoom240, zoom256, zoom288, zoom320,
square
```

**三道必须看的自证**

1. **头结构自证**（`predict_tta.py` 首行打印，从检查点自动读取，**无需 `--head`**）：
   ```
   [tta] lora_best.pt best_ep=5 best_val_acc=0.7653 r=16 hidden=1024 targets=q,k,v,out,fc1,fc2
   ```
   ★★ **必须确认 `hidden=1024`**。若显示 `hidden=0` ⇒ 说明头没按训练时的结构重建，
   最终预测会整体错。同理 `targets` 必须与训练一致（读不到时会**静默退回** `q,k,v,out`，
   那样注入层与训练不符）。

2. **形状自证**（出包脚本打印）：
   ```
   [自证] probs_test shape=(37444, 750) dtype=float16
   [自证] ✅ 形状正确
   ```
   形状不符 ⇒ **立即中止**（本项目出包脚本内置此断言并 `exit 1`）。

3. **类计数分布自证**（`calib_sinkhorn_apply.py` 打印）：
   ```
   [bal] 校正前: max= 160 中位=  48 均值=  49.9 min=  0 标准差= 20.3 超额=13.81%
   [bal] 校正后: max=  60 中位=  50 均值=  49.9 min=  0 标准差=  3.7 超额= 2.11%
   ```
   ★ 测试集类别均衡 ⇒ 每类期望 **37444/750 = 49.93**。
   校正后**标准差必须落在 2.6~3.7、超额 ≈2%**。
   若标准差仍在 18~20 ⇒ **说明漏了这一步校正**（本项目 `chainAB` 就是这么错的）。

> ★ 另有一道**分辨率守卫**：`load_lora_model` 会把检查点里记录的 `img_size`
> 与当前 `C.IMG_SIZE`（由 `AIC_IMG_SIZE` 驱动）比对，不一致直接中止 ——
> 因为拿 288 训练的权重在 224 下出包会**静默关掉位置编码插值**、把 TTA 几何全算错。

## 5. ★★ 已知"静默错误"清单（复现时必须避开）

| # | 坑 | 症状 | 防线 |
|---|---|---|---|
| 1 | **`AIC_IMG_SIZE` 漏设** | 用 224 出包，分辨率与检查点不匹配 | 出包脚本分辨率守卫会 🛑 中止 |
| 2 | **读错概率文件** | `ls -t probs_test_*.npy \| head -1` 会取到**别的实验**的文件 | **必须显式传路径 + `argmax` 与外发 CSV 逐位比对** |
| 3 | **漏做 Sinkhorn 校正** | 类计数标准差 18~20（而非 3.x）⇒ 掉约 1.76pp | 出包后查标准差 |
| 4 | **类别映射退化为顺序编号** | 提交编号全错 ⇒ 0 分 | `write_submission` 默认拒绝写出；审计行必须显示 `prefix_contiguous` |
| 5 | **`--limit` 与 `--track-lowsim` 同用** | 低相似掩码按全量标签序索引，`--limit` 后索引错位 ⇒ **不报错、静默算错** | 代码已硬拦（`SystemExit`） |
| 6 | **训练脚本含 CR 换行** | bash 先崩 | 每个 `.sh` 开头有 CR 闸门（`exit 9`） |
