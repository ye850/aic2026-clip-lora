**我的错误在哪：**

我用一个**特定探针的失效**（`s_own ≡ P(标签)` 被 `argmax` 折叠 ⇒「预测错且 s_own 高」
恒为空）去否证了**整个官方鼓励的方向清单**。

但 `s_own` 只是估计置信度的**一种**方式（用 OOF 概率）。官方说的"置信度建模"
可以是：
- 训练**过程中**的 loss 轨迹 / 预测稳定性（不需要 OOF 后验）
- **多增强视图**的一致性（这正是用户提的第二支柱！）
- 小 loss 准则（small-loss，`co-teaching` 系列的标准做法）
- 累计预测 / 历史一致性（`SELFIE`、`DivideMix` 系列）

⇒ **「`s_own` 这条路不通」≠「置信度建模这条路不通」。** 我把前者当成了后者。

**⇒ 撤回："只剩语义层"和"路线走尽"两个结论。**

**★ 更该注意的是：官方参考资源直接列了两篇噪声标签方法**：
- **JoAPR**（CVPR 2024）—— cleaning the lens of prompt learning for VLM
- **TrustCLIP**（ACM MM 2025）—— **Learning from Noisy Labels via Semantic Label
  Verification and Trust-aligned Gradient Projection**

我此前把这两篇判为"不适用"（JoAPR 是 loss-GMM；TrustCLIP 需类名 zero-shot）就搁下了。
**但组委会把它们列为参考资源，等于在说"这条路是通的"。**
⇒ **这两篇需要重读**，尤其 TrustCLIP 的 `trust-aligned gradient projection`
   部分（**梯度投影**不需要类名，只有 `semantic label verification` 需要）。

## 二、逻辑反向错误（推断方向搞反了）

### 2.1 ★★★★★ 「错分样本离本类类心远 ⇒ 排除错标」—— **方向反了**

| | 内容 |
|---|---|
| **我写的** | "错分样本与本类类心的距离排名**中位 62**……⇒ 与'域差/难样本'一致，**与'标签错'不一致**" |
| **错在哪** | **标签错的样本，本来就该远离「它被分到的那个类」** —— 因为那个类是错的。 |

我的论证逻辑是：错分样本与"预测类"类心距离远 ⇒ 不像是标签错。
但换个说法就露馅了：**如果一张图的标签是错的，那么模型预测到"真类"时，
它当然会离"错标签那个类"很远。** 我测的正是"离本类（=被分到的类）远"，
这个读数**与错标完全兼容**。

⇒ **本类类心距离排名中位 62，既可以被"难样本"解释，也可以被"错标"解释。
它不能排除整任何一个。我把一个双向兼容的观测单向读成了"排除错标"。**

★ 而且我连"这个读数支持难样本"都不该说 —— 正确的说法是：
**这个读数在两种假设下都预期出现，因此它对区分两者没有信息量。**

### 2.2 ★★★★ 「余弦差 0.019 ⇒ 域差解释力≈0」—— **无依据的换算**

| | 内容 |
|---|---|
| **我写的** | "Δ 全分位只有 −0.017~−0.029 ⇒ 量级差两个数量级，**不可能造成 23.1pp 落差**" |
| **错在哪** | **我没有任何依据把"特征余弦的差"换算成"准确率的差"。** |

750 类 argmax 决策面上，很小的几何变化**完全可能被放大**：
类间间隔本来就很窄（此前实测冻结特征 margin ≈ −0.0038），
在这种尺度下 0.019 的相似度变化**足以翻转大量样本的决策**。

⇒ **能说的**：域差在**特征几何上**是小的（Δ≈0.019，全分位一致）。
⇒ **不能说的**：域差"解释力≈0"、"不可能是主因"。
⇒ **要判断域差对准确率的贡献，需要的是端到端对照实验**（例如把测试图重采样成
   训练图的成像条件后重测），**不是几何量的换算。**

## 三、把弱信号升级成定理（用户指出的核心问题）

### 3.1 ★★★★★ 我混淆了「探针失效」与「机制无效」

| 事件 | 我当时的结论 | 应修正为 |
|---|---|---|
| `_probe_true_noise.py` 抽样池太小 | "**这条探针判死**" ✅ 对 | **探针失效**，标签噪声率**未知** |
| `_probe_label_trust.py` 信号弱 + 结构性为空 | "带权标签修正**判死**" | **`s_own` 这一种置信度估计失效**；不等于"置信度建模"失效 |
| `_probe_val_inflation.py` 效应量小 | "假设 C **判死**" | 近重复污染**存在但效应量小**；"判死"这个词用得太重 |
| 三个假设 A/B/C 全未证实 | "**连落差在哪都还没定位**" | 这是对的 —— 但**不该顺势推出"路线走尽"** |

**根因**：我每得到一个否证就写一次"判死"，然后**把三个否证叠加成"整条路走尽"**。
这是**不可加的**：A/B/C 是**三个归因假设**，否证它们**只说明"没找到主因"**，
**完全不说明"没有可做的机制"**。

⇒ ★★ **铁律：否证归因假设 ≠ 否证方法方向。这两件事之间没有任何蕴含关系。**

### 3.2 NCM 0.0286 / CLIP 探针 —— 你说得对

| | 内容 |
|---|---|
| **我此前的用法** | 用"全 750 类 NCM = 0.0286"论证"冻结特征无类间间隔 ⇒ 几何/统计/聚类全灭" |
| **你的纠正** | NCM 是**一个特定冻结特征、特定类心分类器**的结果，**不能充当微调模型的上限** |
| **同意的补充** | 我自己后来也发现 20/30 类探针**选样偏容易**（早期 0.89 不能外推）⇒ 这本身就说明**探针结论对选样极敏感** |
| **结论** | **撤回"特征弱到无路可走"**。只能说：**该冻结特征 + 该分类器组合下表现差**，$不构成骨干或方法上限的证据。 |

★ 而且"少数图片能被 CLIP 判成鸟/花/鼠妇"**不能**证明它能做 750 类细粒度区分 ——
反过来也**不能**证明它不能（那就是 3.1 的同一个错误，换个方向）。

## 四、仍然站得住的结论（这些我核对过，保留）

| # | 结论 | 为什么站得住 |
|---|---|---|
| **1** | **"训练集 33.8% 标签噪声率"是循环论证** | `1 − diag(T).mean()` 在类先验均衡时**恒等于** `1 − 模型类宏平均准确率`。这是**静态代数证明**，不依赖任何探针、任何样本量。★ 你的表述"更像模型与观测标签的分歧率"与此一致 |
