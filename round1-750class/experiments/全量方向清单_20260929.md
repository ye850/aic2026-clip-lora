## 四、⚠️ 明确**不建议做**的（附理由，避免反复纠结）

| 方向 | 不做理由 |
|---|---|
| 完整自监督预训练（SimCLR/DINO） | **前提不成立**：我们有 **148695 张全标注**（监督信号本就强），且骨干是 **CLIP（4 亿图文对）** ⇒ 边际收益≈0；成本却最高 |
| `q75` / 三维全对齐缓存 | 榜分 **−1.88pp** 已实锤；机制是"**收窄**训练分布"，与剂量曲线相悖 |
| 长尾专用方法（LDAM/Balanced Softmax） | 数据**长尾很轻**（头尾比 49.6×、Gini 0.0956、有效类数 736.1/750） |
| zero-shot / 文本先验 | 本机 probe **实测失败**（CLIP 同属三蓝鸲都分不清，余量仅 0.0004~0.018） |
| 几何增强（RandAugment 族） | 源码明确"几何一律不动"是**刻意取舍**：会毁掉 TTA 的 rc0..rc15 视图一致性 |
| 类内素材清洗 / 类间分离 | 属性分析实测：与类准确率相关系数 ≈ 0（−0.017 / +0.081） |
| 多模型集成 / soup | 规则严禁 ⇒ 罚则是取消资格 |
