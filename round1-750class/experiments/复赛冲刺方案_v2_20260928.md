# 复赛冲刺方案 v2（2026-09-28 23:05 定稿）

## 一、新结论（决定一切的三条）

| # | 结论 | 证据 |
|---|---|---|
| 1 | **域差异是多维的**：质量 92→75、色度抽样 4:4:4→4:2:0 | `_jpeg_subsampling_probe.py`：测试图 **4:2:0**；干净缓存 **4:4:4**；q75 缓存 **4:2:0** |
| 2 | **q75 缓存两维同时对齐** ⇒ 同尺 +6.01pp（0.8150 vs 冠军 0.7549） | 同一把 `_val_q75` 尺、base 单视图、448、全量 7537 张 |
| 3 | **二次压缩几乎无效**：degq（q92 缓存上再压 q75）仅 +0.44pp | degq 同尺读数 0.7593 |

★ **推论**：训练缓存 `_preproc` 把原图的**抽样多样性**（4:2:0 一半 / 4:4:4 一半）**归一成 4:4:4**，
与"把质量归一成 92"是同一个错误 ⇒ **它亲手抹掉了本来与测试域一致的那一半**。

⇒ **「三维全对齐」缓存是一个尚未验证、但有明确机制依据的候选。**

## 三、三个情景（按 09-29 榜分分支）

### 情景 A：q75pack 榜分 ≥ 75.5（即 +2.3pp 以上）— 概率约 35%
**动作：全面压上 q75/域对齐路线**
1. 立刻生成**三维全对齐缓存**（长边500 + q75 + 4:2:0，全量 148695 张）
2. 训练 `r448full3`（三维全对齐）⇒ 与 q75 臂对比
3. `q75` 多 seed（3/4/5）⇒ 免费的 max 采样
4. 每天 2 次额度**全部**给这条线的不同包

### 情景 B：q75pack 落在 73.8~75.5（+0.5~2.3pp）— 概率约 40%
**动作：谨慎推进 + 保留确定性路线**
1. 同样先做三维全对齐（成本低、机制明确）
2. 补齐"选优"（现在 q75 用的是**中断状态**）
3. 但**每个额度都要有一个"确定性包"兜底**（多交不同包 = 免费采样）

### 情景 C：q75pack ≤ 73.8（无变化或变差）— 概率约 25%
**动作：止损，转确定性路线**
1. q75 路线**降级为学术记录**，不再投入训练
2. 重心转向 **额度兑现**（13 天 26 次，交不同 seed/后处理的独立包 ⇒ 免费 max 采样）
3. 把时间投到 **10/07 代码包交付链** + **作品文档** + 半决赛准备
