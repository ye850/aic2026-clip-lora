## 二、实测 ①：标签噪声率的**独立**测量（不依赖任何模型预测）

### 为什么必须重测（这是一个前提性错误）

项目里那个 **"训练集 33.8% 标签噪声率"** 数字来自
`src/noise.py::estimate_transition_matrix(method="confusion")`，而它的 T 完全由
**OOF 预测 vs 标签**构造：

```
A[k, j] = P(pred = j | obs = k)
T[j, k] = A[k, j] * pi_obs[k] / pi_true[j]
"噪声率" = 1 - diag(T).mean()
```

当 `pi_obs ≈ pi_true` 时 `diag(T)[k] ≈ P(pred=k | obs=k)` = **类 k 的模型准确率**
⇒ `1 - diag(T).mean()` 就是 **`1 - 模型类宏平均准确率`**。

**这是循环论证**：用模型的错误去证明"标签很脏"。
而项目围绕这个数字建了整整一条抗噪路线（降权 / 前向校正 / 标签修正 / sel-frac）。

### 独立测法：近重复一致性

两张视觉上几乎相同的图 ⇒ 来自**同一个真实类**（这是"近重复"的定义）。
设真实噪声率 e（均匀随机错标到其余 K−1 类）：

```
观测标签相同的概率 = (1-e)^2 + e^2/(K-1)
观测标签不同的概率 c ≈ 2e - e^2
⇒ 反解 e = 1 - sqrt(1 - c)
```

用**原始 CLIP 特征**（不用微调后特征 —— 后者会把标签信息吸收进特征，
人为压低冲突率）。结果给的是**上界偏保守**估计（细粒度数据里不同类也可能极相似）。

### 实测结果（`scripts/_probe_true_noise.py`，CPU 25.6s）

```
feat_train (148695, 512)；labels (148695,)

[原始 CLIP 特征]  30000 个 query；top1 余弦 中位 0.9178 / p90 0.9635 / max 1.0000
            相似度档        n       标签一致      冲突率c        反推噪声率e(上界)
     0.900~0.950      15671     0.1135    0.8865            0.6632
  ≥0.95 累计: n=  5115  冲突率 0.8657  ⇒ 反推 e 上界 0.6335
  ≥0.99 累计: n=  1225  冲突率 0.9200  ⇒ 反推 e 上界 0.7172
  全体 top1: n=30000  标签一致率 0.1064  ⇒ 反推 e 上界 0.6738
```

### ★★★ 判读：**这个探针给出的是荒谬结果，必须弃用**

**关键自检**：同一批数据，我用**全库**（非 3 万抽样池）重算了
`train→train top1 标签一致率`：

| 库 | top1 标签一致率 |
|---|---|
| 30000 抽样池（本探针） | **0.1064** |
| **全库** | **0.8765** |

**抽样池把近邻一致率压低了 8 倍。** 原因：1000 个训练样本里，一个类的
近邻大多**不在池内**，于是 top1 落到了别的类上。这不是标签噪声，是**池子太小**。

⇒ **`e 上界 63~72%` 是抽样人工产物，不是标签噪声率。**
⇒ 这条探针**判死**（探针本身不可用，而不是"证明了标签脏"）。

**→ 标签噪声率至今仍是未知量。** 我**不能**说"标签很干净"，
也**不能**说"标签很脏"。这个前提**悬空**。

### ★★★★★ 但这里挖出一个**真正的**病灶

`train→train 近重复` 的原始数字我这次一并看清了：

| 集合 | ≥0.95 近重复占比 | ≥0.99 近重复占比 |
|---|---|---|
| **训练集内部（Tr→Tr）** | **18.80%** | **4.90%** |
| 测试集内部（T→T） | 4.42% | 0.43% |
| 测试→训练（T→Tr） | **0.598%** | **0.000%** |

⇒ ★★★★ **本地留出集里 18.8% 是近重复图，而测试集只有 4.4%**
⇒ 近重复图**靠记忆就能做对** ⇒ **本地 val 被人为抬高**
⇒ 这就是"本地 0.77 / 榜 0.7366"落差的一大部分来源，且**与标签噪声无关**。

## 三、实测 ②：测试集 vs 训练集的**域差**（本轮唯一的正面新事实）

此前"本地尺不能预测榜分"只是一条经验，**从未量化过差多少**。
本轮用冻结 CLIP 特征做了直接测量（`scripts/_probe_domain_shift.py`，CPU 35.7s）。

### 设计

同一份特征、同一套计算，三组对照：

| 组 | 含义 | 作用 |
|---|---|---|
| **Tr→Tr** | 训练图 → 其他训练图（排除自身） | 训练域内部密度，sanity |
| **T→Tr** | 测试图 → **整个训练集** | ★ 跨域可达性 |
| **T→T** | 测试图 → 其他测试图（排除自身） | 测试域内部密度，**域内对照** |

★ 关键：`T→T` 与 `T→Tr` 用的是**同一批测试图**，所以两者之差**就是纯域差**，
不受"测试图被压到长边 500 导致整体余弦偏移"的干扰。

### 实测结果

| 分位 | T→T（域内） | T→Tr（跨域） | **Δ = 跨域 − 域内** |
|---|---|---|---|
| p1 | 0.8046 | 0.7756 | **−0.0290** |
| p10 | 0.8637 | 0.8402 | **−0.0234** |
| p25 | 0.8873 | 0.8667 | −0.0206 |
| **p50** | **0.9098** | **0.8908** | **−0.0190** |
| p75 | 0.9284 | 0.9101 | −0.0183 |
| p90 | 0.9417 | 0.9246 | **−0.0170** |
| p99 | 0.9642 | 0.9468 | −0.0174 |

```
Tr→Tr 中位 0.9201 vs T→T 中位 0.9098  ⇒ 域内密度差 −0.0103
```

### ★★★★ 判读一：域差**很小**，且**低端最大** —— 域差不是 23pp 的主因

**Δ 在所有分位上只有 −0.017 ~ −0.029。**

对照量级：同一个模型在**同一域内**（train↔train）与**跨域**（test→train）
的最近邻相似度，中位只差 **0.019**。这样小的几何漂移，
**不可能**造成 23.1pp 的准确率落差。

⇒ **"本地尺不能预测榜分"的原因不是域差。** 域差确实存在（方向一致、
低端更大 ⇒ 少见的成像条件受域差影响更大），但幅度只有 ~2%。

### ★★★★★ 判读二：**这是本轮最重要的读数**

```
≥0.99  Tr→Tr  4.900%    T→Tr  0.000%    T→T  0.427%
≥0.97  Tr→Tr  9.100%    T→Tr  0.019%    T→T  0.630%
≥0.95  Tr→Tr 18.800%    T→Tr  0.598%    T→T  4.420%
≥0.90  Tr→Tr 71.125%    T→Tr 38.062%    T→T 61.924%
≥0.85  Tr→Tr 94.625%    T→Tr 85.891%    T→T 94.135%
```

★ **`T→Tr ≥0.99 = 0.000%`（37,444 张里一张都没有）、`≥0.95 = 0.598%`**，
而**测试集内部** `T→T ≥0.95 = 4.42%`。

⇒ 测试图在**测试集内部**能找到近重复（4.42%），
但在**训练集里找不到**（0.598%）⇒ **测试集确实是真留出集，无跨划分泄漏。**
（这条此前在 `追90分_本轮根因诊断.md` 已判死，本轮用**更大库+分位全貌**再次确认。）

## 四、实测 ③：误差分解 —— 容量**没有**被高频类吃掉

用户此前的怀疑之一是"320 缓存导致容量花在测试集不存在的模式上"。
本轮按**类频次**做了误差分解：

| 组 | 类频次范围 | 平均类 acc | 该类样本占比 |
|---|---|---|---|
| 组1 | 5 ~ 171 | **0.6823** | 15.1% |
| 组2 | 171 ~ 188 | 0.7491 | 18.2% |
| 组3 | 188 ~ 216 | 0.7626 | 20.0% |
| 组4 | 216 ~ 231 | 0.7452 | 22.6% |
| 组5 | 231 ~ 248 | 0.7485 | 24.2% |

```
>=200张: 342 类, 类acc均值 0.7519
<100张 :  13 类, 类acc均值 0.2310
整体 acc = 0.7462   宏平均类acc = 0.7375
```

⇒ **除极少数（13 个）超低频类外，各组类 acc 几乎持平（0.745~0.763）**。
⇒ **不存在"高频类吃掉了低频类"的长尾崩塌。** 类频次基本均衡（176~248），
所以"均衡校正"这个已用掉的杠杆，其剩余空间确实接近零。

### 错分方向：不在类心邻域

```
=== 错分方向：pred 与本类在类心空间的距离排名 ===
  错分样本 n=20000
   该类心距离排名 <=  0 占比 0.0355
   该类心距离排名 <=  1 占比 0.0638
   该类心距离排名 <=  5 占比 0.1446
   该类心距离排名 <= 10 占比 0.2101
   该类心距离排名 <= 50 占比 0.4598
  中位排名 62.0
```

⇒ ★ **错分样本与"本类类心"的距离排名中位 62**（750 类里排 62），
只有 3.55% 的错分样本"离本类类心最近"。
⇒ 这说明错分**不是**"类心之间互相混淆"（那样排名应该很小），
而是**样本自身落在类心够不着的地方** ⇒ 与"域差/难样本"一致，与"标签错"不一致
（标签错的样本，其特征通常仍在**真实类**附近）。

## 六、这对"23.1pp 泛化落差"意味着什么（新归因）

★★★ **本节含一次自我否证 —— 我在写完 §二后立刻提的假设 C，被我自己随后的
实测推翻。原文保留在下方"已撤回"块里，作为反面教材。**

### 6.1 我提的假设 C（**已撤回**）

> **假设 C（撤回）**：本地 val 被近重复灌水 ⇒ 本地 0.77 虚高，榜分才 0.7366。
> 依据：本地留出集近重复 **18.97%**，测试集仅 **4.42%**，差 **14.55pp**。

**这个假设听起来很有力，但它是错的。** 我随即做了直接检验
（`scripts/_probe_val_inflation.py`，5.5s）：

| 臂 | 近重复层 acc | 非近重复 acc | **Δ（近重复 − 其余）** |
|---|---|---|---|
| `r448pl3`（冠军同构） | 0.8469 | 0.8315 | **+0.0153** |
| `d_r448ul4` | 0.8434 | 0.8364 | **+0.0069** |
| `r448up_ps` | 0.8119 | 0.7554 | +0.0565 |

⇒ ★★★ **近重复图的优势只有 +0.7 ~ +1.5pp，不是"靠记忆就能做对"那种压倒性优势。**

原因：细粒度近重复图（同种动物的不同照片）**彼此仍然很难**，
不像通用数据集的近重复那样"几乎是同一张图"。
**我把"近重复"这个概念从通用数据集直接搬过来，高估了它的易度。**

### 6.2 直接检验：重加权到"测试集同构"，排序会变吗

把留出集按测试集的近重复水位（4.42%）重加权：

| 臂 | 原始 val | **重加权 val** | 水位 |
|---|---|---|---|
| `r448pl3`（冠军同构） | 0.8344 | **0.8322** | −0.0022 |
| `d_r448ul4` | 0.8377 | **0.8367** | −0.0010 |
| `r448up_ps` | 0.7661 | **0.7579** | −0.0082 |

```
按原始 val 排序: d_r448ul4 > r448pl3 > r448up_ps
按重加权 val 排序: d_r448ul4 > r448pl3 > r448up_ps
⇒ 排序不变
```

⇒ ★★★ **近重复污染是真实存在的，但它的量级（每臂 0.1~0.8pp）不足以
解释 23.1pp 落差，也不改变任何选包决定。**
⇒ **假设 C 判死。**

> 教训（已落成铁律 57）：**"某偏差存在"不等于"该偏差解释了落差"。**
> 发现一个统计上有意义的污染后，**必须量它的效应量**，
> 而不是直接把它升格为"主因"。我这次差点就这么干了。

### 6.3 三种解释的最新状态（全部未被证实）

| 解释 | 状态 | 依据 |
|---|---|---|
| A. 域差（测试图与训练图风格不同） | **❌ 已排除** | 域差仅 ~0.019 余弦，量级差两个数量级 |
| B. 训练集标签脏 ⇒ 模型学错 | **⚠️ 前提悬空** | 33.8% 是循环论证；独立探针自身失效 |
| C. 本地 val 被近重复灌水 | **❌ 已排除** | 近重复层优势仅 +0.7~1.5pp；重加权后排序不变 |

⇒ ★★★★★ **最诚实的结论：23.1pp 泛化落差的来源，目前一个都没被定位。**
⇒ 这本身是重要信息 —— 它说明我们**连"落差在哪"都还没找到**，
在找到之前，任何"针对落差"的机制设计都是盲投。
