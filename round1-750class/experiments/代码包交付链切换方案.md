## 二、冠军 LoRA 配方（执行时逐字复制）

训练（`src/finetune_lora.py`）：
```
--epochs 12 --batch 96 --workers 8 --lr 2e-4 --head-lr-mult 5
--targets q,k,v,out,fc1,fc2 --dropout 0.1 --mixup 0.2
--ema-decay 0.999 --ema-start 1
--preproc --track-lowsim --select-by lowsim_a --log-every 200
--unfreeze-last 4 --backbone-lr-mult 0.1 --seed 0
```
（= `queue_0926v23.sh` 的 COMMON，与冠军 `d_r448up` 逐字一致）

推理（`scripts/predict_tta.py`）：
```
--lora outputs/<tag>/lora_best.pt --views best --fusion power --fusion-t 4
--workers 4 --batch 128 --out-dir outputs/submission_<tag>
```

环境：Python 3.12 + **torch 2.12.1 + CUDA 13.0（cu130）**（已对齐，见 §三备注）。

   关键：**不能**让 json 成为"外部写死的前置文件"，必须是代码自动产出。
