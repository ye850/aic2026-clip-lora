## 一、诊断 1：GMM-on-loss 软权重（NEARL-CLIP 路线）❌ 不成立

**文献动机**：对逐样本交叉熵损失拟合**两分量 GMM**，得到 clean/noisy 后验，
取代固定置信阈值做软权重。

### 实测（`scripts/gmm_weight_make.py`，纯 CPU）

**① 用 in-sample 教师（`outputs/pseudo/probs_train.npy`，ul4 在本数据上训过）**

```
原标签交叉熵直方：
  [ 0.000,  2.763)  136458   ← 96.7% 挤在这里
  其余长尾 ...
```
⇒ EM **两分量塌成同一个**（mu 相同、π 各 0.5）⇒ 脚本守卫正确中止。
**根因**：教师 in-sample ⇒ 它**背下了原标签** ⇒ `p(y_原)≈1` ⇒ 损失全 ~0 ⇒ 无峰可分。

**② 改用无偏的 OOF 损失（`outputs/oof_local/oof_probs.npy`，本地，446MB）**

```
OOF 原标签交叉熵: 中位=0.0227 p75=1.0572    79.8% 落在 [0, 1.974)
GMM 收敛后：干净分量 mu=0.0039 sd=0.0057 π=0.5045   ← 又塌成 0 处尖峰
           噪声分量 mu=2.8416 sd=3.7173 π=0.4955
           ⇒ P(clean)<0.3 的样本 = 72865 张 = 49.00%
```
⇒ **它拟合的是"0 处尖峰 + 其余"，不是"干净 vs 噪声"** ⇒ 会把**一半训练集**当成噪声压低。

### ★ 结论
**本数据的"干净/噪声"在损失分布上不可辨识。** 这与本项目既有实测一致：
错分样本 **`rank(y)` 中位 = 5.0** ⇒ **标签大体是对的**，模型的错来自**视觉重叠**而非错标。
⇒ GMM-on-loss **放弃**，不硬凑。

## 二、诊断 2：类原型一致性（PICS 路线）❌ 不成立

**文献动机**（arXiv 2507.22075）：用**类内特征紧致度 + 类间特征分离度**评估伪标签正确性。

### 实测（云端 `outputs/pseudo/feat_train_clip.npy`，(141158, 512) 冻结 CLIP 特征）

```
类内相似度 own   : 中位 0.8771（p10 0.7737）
最近异类相似度   : 中位 0.8815      ← ★ 比本类还像
margin = own - best_other : 中位 −0.0038，p10 −0.0569，p90 +0.0288
margin < 0 的占比 : 55.99%
```

★★★ **一半以上的训练样本，离"别的类的原型"比离"自己类的原型"更近。**

### 与教师证据的关系（说明它作为筛子的**无选择性**）
| 量 | 值 |
|---|---|
| 硬阈值（τ≥0.8 且不一致）候选 | 4520 张 |
| ↳ 其中 margin<0 | 4350 张（96.2%） |
| ↳ 其中"教师建议类 == 最近异类原型" | 1455 张（32.2%） |
| **全体样本 margin<0** | **56.0%** |

⇒ 候选里 96.2% 是负 margin，但**全体也有 56% 是负的** ⇒ **这个判据几乎没有选择性**
（它把略多于一半的所有样本都标成可疑）。
⇒ **PICS 路线放弃。**

## 三、★★★ 两条诊断共同指向的根因：**冻结特征的类间间隔 ≈ 0**

把本项目**所有**"在特征空间做几何/统计"的方法放在一起看，失败原因完全一致：

| 已关闭的方法 | 当初的说法 | **真实原因** |
|---|---|---|
| kNN / 检索式 | "LoRA 特征 kNN 仅 0.1196 ⇒ 特征端无结构" | 类间无间隔 ⇒ **距离度量不可用** |
| NCM / 原型分类 | 同上 | 同上 |
| SupCon（表征约束） | 本地 +0.23pp，p=0.88（今天固定分桶） | 表征约束**改不了"类间本就没有间隔"** |
| **GMM + 软权重**（今天） | —— | 标签大体是对的 ⇒ **"干净/噪声"不可辨识** |
| **PICS 原型一致性**（今天） | —— | margin **无选择性**（全体 56% 为负） |

★ 注意：`kNN 0.1196` 与 `margin 中位 −0.0038` 是**两个独立测量**，互相印证。
⇒ **"特征端无结构"这个当初被判为"过度解读"的说法，现在有了正面证据：它是对的。**

### ★★ 由此推出的方向性结论
**任何在冻结特征上做事后几何/统计/聚类/原型的技巧，在本数据上原理性无效。**
剩下的杠杆只有三类：

| # | 类别 | 代表 | 状态 |
|---|---|---|---|
| **①** | **训练侧改善特征几何** | 容量↑(r32 ❌榜分负)、SupCon(❌无效果)、SCE(❌无差异) | **已大量试过，全无效** |
| **②** | **注入更多视觉证据** | 分辨率（384→448 **+1.32pp**；768 ❌源图不够）、**几何尺度扩宽 rrc** | **rrc 在跑（今晚）** |
| **③** | **用教师+近邻投票改标签**（不依赖原型/距离） | **lfix v1/v2** | **已排队（今晚）** |

⇒ **今晚在跑的 `rrc` 与 `lfix` 不是"随便挑的两个"，而是穷尽了其他类之后剩下的两条。**

## 五、一句话结论

> 今天按文献试的三条新机制（GMM 软权重、原型一致性、以及此前的 kNN/NCM 一族）
> **全部失败，而且失败原因是同一个**：
> **冻结 CLIP 特征在 448 下的类间间隔 ≈ 0**（margin 中位 −0.0038、56% 为负），
> 且**标签大体是对的**（rank(y) 中位 5.0）。
> ⇒ 瓶颈是**特征几何**问题，不是"缺一个聪明的后处理"。
> ⇒ 只剩两条路：**注入更多视觉证据（分辨率/尺度扩宽）** 与 **教师+近邻投票改标签**，
> 而这两条今晚都在跑。
