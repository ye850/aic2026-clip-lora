## 直接回答

> **「是我们的模型不够强吗？」**

**答：主要是，但不是"训练得不够"。三层证据：**

| 证据 | 读数 | 含义 |
|---|---|---|
| **多数错分在冻结特征空间里连最近邻都分不开** | 1,156/1,627 = **71%** | 连"查最像的训练样本"都对不了 ⇒ **输入信息本身就不够** |
| **错分时真类就排在前几名** | rank 中位 **6**，rank≤10 占 **60.3%** | **不是"认不出来"，是"认出来了但排第二"** |
| **margin 极低区错分率畸高** | margin<0.8 区 **68.4%**，>0.8 区仅 **13.4%** | 错分集中在"两个候选打得很平"的地方 |

⇒ ★★ **一句话：瓶颈是"细粒度视觉区分力"，不是"训练不足"、不是"输入质量"、不是"标签噪声"。**
⇒ 这与整个项目已投的所有方向**正交**——所以它们的读数都贴在 0 附近。

## 一、错分长什么样：完全散乱，不是少数难类

| 读数 | 值 |
|---|---|
| 错分张数 | 1,627 / 7,536（21.6%） |
| **不同的（真值→预测）对数** | **1,467 个** |
| top5 对占 | **1.7%** |
| HHI | **0.0008** |
| 涉及真值类 | **553 / 750** |
| 每类错分 | 中位 **2** 张、max 10、标准差 2.07 |

对照零分布：若完全随机散布，每对期望 0.0029 张，而观测 top1 = 7 张
⇒ **远超随机**（有结构）**但结构极弱**（top5 仅 1.7%）。

**且错分数与类别样本量不相关**：

| 相关 | 值 |
|---|---|
| Pearson | r = 0.0714 |
| **Spearman** | **0.0473（p = 0.195）** |

⇒ ★★ **大小类别的错分率一样**。
⇒ **否掉"某些类别天生难"的假设**，也否掉"长尾是主因"（与 §4.7 独立吻合）。

## 二、关键对照：同一份冻结 CLIP 特征，kNN 能分对多少？

这是回答"模型够不够强"的**直接证据**——同一份特征，只换分类器。

| | acc |
|---|---:|
| **kNN-1（冻结特征，最近邻）** | **58.15%** |
| kNN-20 投票 | 57.76% |
| **我们的模型（U 冠军，15 视图融合）** | **78.41%** |

**四象限**：

| | 张数 |
|---|---:|
| 两者都对 | 3,911 |
| **kNN 对、我们错** | **471** |
| **我们错、kNN 也错** | **1,156** |
| kNN 错、我们也对 | 1,998 |

⇒ ★ **我们判错的 1,627 张里，1,156 张（71%）连最近邻都分不开。**
⇒ ⇒ 这 1,156 张**不是"模型不够强"**，是**输入特征里就没有那个信息**。

### 2.1 ⚠️ 但那 471 张要单独说（我差点一笔带过）

脚本第一版我写的是"**不是模型不强**"。**这句下得太快，已修正。**

   ⇒ **至少不是"勉强擦边蒙对"**

⇒ ★ 正确写法：**"多数错分在冻结特征空间里不可分"成立**；
**"所以不是模型不强"不成立** ⇒ 见下一节。

## 三、★★★ 那 471 张给出了反向证据：不是"推远"，是"差一名"

| | rank 中位 | rank≤10 占比 |
|---|---:|---:|
| **那 471 张（kNN 对、我们错）** | **5** | **66.9%** |
| 全体错分 | 6 | 60.3% |

⇒ ★★★ **两者的 rank 几乎一样。**
⇒ **模型没有把这 471 张推到远处**——真类就在前几名，
⇒ **它们是"排第二"，不是"排第 500"。**

⇒⇒ **这才是"模型不够强"的真正证据**，而且它精确地指向一点：
**我们缺的是"在两个打平的候选之间做出正确判别"的能力。**

## 五、⇒ 所以"为什么判错"，按证据排序

## 六、一个必须说清的张力

§4.9.6/§4.10 测出：测试集比验证集难 3.15pp，其中 **90.6%** 由"测试集样本离训练池更远"解释。
§4.9.5 测出：把 val 的错误率函数搬到测试集，覆盖 **89%**。

而本节测出：错分 **71%** 在冻结特征空间里连最近邻都分不开。

⇒ ★ **三者是一致的**：测试集更难，不是因为"训练得不够"，
而是因为**测试集样本在特征空间里离训练池更远 ⇒ 最近邻无从借力 ⇒ 判错**。
⇒ ★★ **这一条把"训练/测试落差"归因和"判错原因"接上了**：
根因是**特征空间的覆盖**，而不是优化或容量。
