# 运行说明与复现指南

**赛题**：面向噪声标签的细粒度图像分类
**团队**：明鉴
**线上成绩**：排行榜最高 **77.7241**（本仓库对应该成绩的模型与结果文件）

---

## 一、方案一句话概括

以 **OpenAI CLIP ViT-B/32** 为冻结骨干，注入 **LoRA** 并解冻视觉塔末 4 层做参数高效微调；
在此之上叠加五项互相正交的机制：**SCE 噪声鲁棒损失 + 冲突组软目标 + 画质退化增强（对齐测试域成像质量）
+ 优化器层 SAM 与 SWA + 教师软标签蒸馏**；
推理端用 **15 视图 TTA（power 融合 t=4）+ Sinkhorn 类别均衡校准** 直接产出提交文件。

## 五、训练

```bash
cd $AIC_ROOT
AIC_ROOT=$AIC_ROOT AIC_IMG_SIZE=448 PYTHONPATH=$AIC_ROOT/src \
python scripts/arm_runner.py -- \
  --epochs 12 --batch 96 --workers 8 --lr 2e-4 --head-lr-mult 5 \
  --targets q,k,v,out,fc1,fc2 --dropout 0.1 --mixup 0.2 \
  --ema-decay 0.999 --ema-start 1 --unfreeze-last 4 --preproc \
  --track-lowsim --select-by lowsim_a --log-every 200 \
  --hidden 1024 --kind sce --r 16 \
  --soft-conflicts configs/dedup_soft_conflicts.json \
  --sam-rho 0.05 --swa --swa-start 5 \
  --degrade p=0.6,max_side=640,q=70-80 \
  --kd-probs <教师软标签目录> --kd-lambda 0.3 \
  --ckpt outputs/lora.pt --out-dir outputs/
```

### 关键超参说明（均为消融后确定，请勿随意改动）

| 参数 | 取值 | 说明 |
|---|---|---|
| 分辨率 | 448 | 测试图短边中位 375，训练缓存 320；448 覆盖测试域细节 |
| LoRA | r=16，targets `q,k,v,out,fc1,fc2` | 72 层注入，可训练占比约 20.8% |
| 解冻 | 视觉塔末 4 层 | 全量微调反而更差，末 4 层为最优点 |
| 损失 | `sce`（软目标与硬标签逐位自洽） | 噪声标签鲁棒 |
| 软目标 | `configs/dedup_soft_conflicts.json` | 1,877 个文件级冲突组；组总权重=1、组内均分 |
| 画质退化 | `p=0.6, max_side=640, q=70-80` | **对齐测试域真实存在的成像质量**；加大到 q50-95 会变差 |
| SAM | `rho=0.05`（强制关闭 AMP 走 fp32） | 优化器层，求平坦极小 |
| SWA | `--swa-start 5`（窗口 ep5–12） | **此值为关键**：改成 8 实测掉 0.55pp |
| KD | `lambda=0.3`，教师为本队自训权重 | 软标签**只来自训练集**，不使用测试集任何信息 |

## 六、验证

```bash
AIC_ROOT=$AIC_ROOT AIC_IMG_SIZE=448 AIC_AUDIT_EXPECT_VAL=7536 PYTHONPATH=$AIC_ROOT/src \
python scripts/tta_lora_eval.py \
  --lora 模型目录/lora_best.pt \
  --views base,flip,rc0,rc1,rc2,rc3,rc4,rc5,rc6,rc7,zoom240,zoom256,zoom288,zoom320,square \
  --save-probs outputs/probs_val.npy --workers 16
```

- `--select-by lowsim_a`：按"低相似子集 A 半"选轮，该口径全流程一致。
- `AIC_AUDIT_EXPECT_VAL=7536`：本方案留出集实际为 7536 张（清单枚举顺序相关），
  与脚本默认期望值 7537 不同，需显式指定，否则脚本会以"切分复刻不一致"为由中止。
- 输出中 `safe+分辨率`（15 视图）一行即生产出包所用的视图组合。

## 七、推理与提交文件生成

```bash
# 1) 15 视图 TTA + power 融合（t=4），输出测试集概率
AIC_ROOT=$AIC_ROOT AIC_IMG_SIZE=448 PYTHONPATH=$AIC_ROOT/src \
python scripts/predict_tta.py \
  --lora 模型目录/lora_best.pt \
  --views best --fusion power --fusion-t 4 \
  --out-dir outputs/pack --save-probs outputs/probs_test.npy --force --workers 16

# 2) Sinkhorn 校准到均匀类别边缘（测试集类别均衡，共 750 类）
python scripts/calib_sinkhorn_apply.py \
  --probs outputs/probs_test.npy --out-dir outputs/submission --target uniform

# 3) 校验提交文件
python scripts/check_submission.py outputs/submission/pred_results.zip
```

- 单个文件 `pred_results.csv`，UTF-8，无表头
- 每行 `文件名.jpg, 类别号`（逗号后一个空格，类别号为 0..749）
- 行数 **37,444**，与测试集一一对应，文件名不重复
- 打包为 zip，zip 内仅该一个文件

## 九、说明与边界

0. **另见**：逐步复现手册（两条路径 + 每步判据 + 偏差处置）与**实验记录附录**
   （含被采纳机制、被证伪方向与两条判据）见同目录《复现方案.md》。
1. **提交权重的构成**：训练结束后以 `--swa-start 5` 对 ep5–12 的原始权重做滑动平均，
   平均值即为提交权重（标准 SWA 用法）。平均后的权重在同一把留出集上单独评测并打印，
   便于核对。
2. **训练侧不使用任何测试集信息**：画质退化参数来自对测试集成像特征的独立测量（作为设计动机），
   训练输入、软目标、样本权重均只由训练集自身导出。
3. **单模型单流程**：本方案全程单一模型、单一推理流程，未使用多模型集成或输出级投票。
4. **完整实验记录**：含中途被证伪的机制（例如推理分辨率高于 448 会下降、SWA 窗口后移会下降）
   见 `脚本清单.md` 与随附技术报告。
