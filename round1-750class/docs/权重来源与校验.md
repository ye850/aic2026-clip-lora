# 权重来源与校验

> 本节对应复现包收尾清单第 3 项：**权重来源写明**。
> 目的：让审核方能在不依赖任何第三方微调权重的前提下，复现出与本队提交物一致的底座。

---

## 1. 底座视觉编码器：CLIP ViT-B/32

| 项 | 取值 |
|---|---|
| 模型架构 | CLIP ViT-B/32（OpenAI 原始架构，ViT-B + Transformer 文本塔）|
| 权重来源 | **HuggingFace 官方仓库 `openai/clip-vit-base-patch32`** |
| 权重性质 | OpenAI 官方公开发布权重，**非任何第三方微调 / 非自训** |
| 合规依据 | 赛规仅锁定三件事：CLIP ViT-B/32、权重仅 OpenAI 官方版、禁集成。HF 官方仓库 `openai/clip-vit-base-patch32` 即 OpenAI 官方发布权重，完全满足要求。|

## 2. 加载路径说明（为何代码里看到的是本地目录）

训练 / 推理代码通过环境变量 `AIC_CLIP_DIR` 指向本地缓存目录
`models/clip-vit-base-patch32`。该目录是官方权重的**本地镜像**（首次运行时由
`openai/clip-vit-base-patch32` 下载缓存），并非一份独立的、被改动过的权重。

> 若本地镜像缺失或链接异常，代码会回退到从 `openai/clip-vit-base-patch32` 在线拉取，
> 二者是同一份官方权重，不影响数值结果。

## 3. 本队自训权重（与底座权重区分清楚）

| 权重 | 来源 | 是否官方 |
|---|---|---|
| 底座 CLIP 编码器 | `openai/clip-vit-base-patch32` | ✅ OpenAI 官方 |
| LoRA 适配器（`lora_best.pt`）| 本队在训练集上微调得到 | ❌ 自训（应随复现包提供）|
| KD 教师（`d_sam_swa_f/lora_best.pt`）| 本队自训、单教师、软标签只来自训练集 | ❌ 自训（应随复现包提供）|

底座权重**不随包提供**（体积约 600MB+，且官方可重新获取）；复现包通过下面第 4 节的
拉取命令 + 校验和确保"用的是同一份官方权重"。

## 4. 复现时如何获取并校验底座权重

```bash
# 拉取官方底座（需联网；或改用已缓存的本地镜像目录）
python -c "from transformers import CLIPModel; \
           m = CLIPModel.from_pretrained('openai/clip-vit-base-patch32'); \
           m.save_pretrained('./models/clip-vit-base-patch32')"
```

**校验要点（复现审核时可逐项核对）：**

1. **架构一致性**：`patch_size == 32`，`vision_width == 768`，`vision_layers == 12`，
   `embed_dim == 512`，与 ViT-B/32 规格吻合。
2. **关键张量名**（取自官方 `pytorch_model.bin` 的 `state_dict`）：
   - `vision_model.embeddings.class_embedding` / `patch_embedding` / `position_embedding`
   - `vision_model.encoder.layers.{0..11}.*`（12 层）
   - `text_model.embeddings.token_embedding` / `text_model.encoder.layers.{0..11}.*`
   - `text_projection`、`vision_projection`、`logit_scale`
3. **数值校验（任选其一）**：
   - 对 `pytorch_model.bin` 计算 sha256，与 HF 官方仓库 `openai/clip-vit-base-patch32`
     发布值比对；
   - 或对随机一张图做 `image_features`，与已知参考向量余弦相似度应 > 0.999。

## 5. 与提交物一致性结论

本队所有提交物（含当前最高分 77.7241 配方）的底座均为**同一份**
`openai/clip-vit-base-patch32` 官方权重；其上叠加的全部增量（LoRA、KD 教师）均为
本队在**训练集**上自训得到，未引入任何测试集信息、未使用任何模型集成。
复现包提供完整的自训权重与拉取 / 校验脚本，确保审核方可独立复现。
