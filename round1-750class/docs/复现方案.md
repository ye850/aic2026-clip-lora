# 复现方案

本文件给出一条**可逐步核对**的复现路径：每一步都写明输入、命令、预期输出与核对判据，
出现不一致时可以立刻定位到是哪一环。

目录约定：全文用 `$AIC_ROOT` 表示工程根目录（自行指定，例如 `<你的工作目录>/aic`），
代码内部不依赖任何固定路径。

| 目标 | 判据 |

## 四、路径 A：推理复现

### A1 环境自检

```bash
python -c "import torch, transformers; print(torch.__version__, torch.cuda.is_available())"
```

预期：打印版本号且 `True`。若为 `False`，说明 CUDA 不可用，需先修环境。

### A2 底座权重就位

```bash
python -c "from transformers import CLIPModel; \
           m = CLIPModel.from_pretrained('openai/clip-vit-base-patch32'); \
           m.save_pretrained('$AIC_ROOT/models/clip-vit-base-patch32')"
```

预期：目录生成，含 `pytorch_model.bin` 与 `config.json`。

### A3 权重加载自检

```bash
python -c "
import torch
o = torch.load('$AIC_ROOT/weights/lora_best.pt', map_location='cpu', weights_only=False)
print(sorted(o.keys()))
print('img_size', o['img_size'], 'best_ep', o['best_ep'], 'best_val_acc', o['best_val_acc'])
print('参数量', sum(v.numel() for v in o['model'].values()))
"
```

**判据**：`img_size = 448`、`best_ep = 12`、`best_val_acc ≈ 0.7935`、参数量 `155,225,584`。

### A4 留出集评估

```bash
AIC_ROOT=$AIC_ROOT AIC_IMG_SIZE=448 AIC_AUDIT_EXPECT_VAL=7536 PYTHONPATH=$AIC_ROOT/src \
python scripts/tta_lora_eval.py \
  --lora $AIC_ROOT/weights/lora_best.pt \
  --views base,flip,rc0,rc1,rc2,rc3,rc4,rc5,rc6,rc7,zoom240,zoom256,zoom288,zoom320,square \
  --save-probs $AIC_ROOT/outputs/probs_val.npy --workers 16
```

**判据**：留出集 7,536 张；输出的 `safe+分辨率`（15 视图）一行即生产口径。
其中 `base` 单视图一行应约 **0.7939**，15 视图一行应约 **0.7986**。

> 说明：脚本默认期望留出集为 7,537 张，本方案实际为 7,536 张（与清单枚举顺序有关），
> 故需显式给出 `AIC_AUDIT_EXPECT_VAL=7536`，否则脚本会以"切分复刻不一致"中止。

### A5 测试集推理与出包

```bash
AIC_ROOT=$AIC_ROOT AIC_IMG_SIZE=448 PYTHONPATH=$AIC_ROOT/src \
python scripts/predict_tta.py \
  --lora $AIC_ROOT/weights/lora_best.pt \
  --views best --fusion power --fusion-t 4 \
  --out-dir $AIC_ROOT/outputs/pack --save-probs $AIC_ROOT/outputs/probs_test.npy \
  --force --workers 16

python scripts/calib_sinkhorn_apply.py \
  --probs $AIC_ROOT/outputs/probs_test.npy \
  --out-dir $AIC_ROOT/outputs/submission --target uniform
```

**判据**：`probs_test.npy` 形状 `(37444, 750)`；出包为单文件 `pred_results.csv`，37,444 行。

### A6 与随附结果文档比对

```bash
python - <<'PY'
import zipfile
def load(p):
    z = zipfile.ZipFile(p); n = z.namelist()[0]
    d = {}
    for line in z.read(n).decode().strip().split("\n"):
        f, _, c = line.partition(",")
        d[f.strip()] = c.strip()
    return d
a = load("$AIC_ROOT/outputs/submission/pred_results.zip")
b = load("<随附结果文档>/pred_results.zip")
k = set(a) & set(b)
diff = [x for x in k if a[x] != b[x]]
print("交集", len(k), "差异", len(diff), "差异率 %.4f%%" % (len(diff)/len(k)*100))
PY
```

**判据**：交集 37,444，差异率 **0.0000%**（推理为确定性流程，视图随机裁剪按样本播种）。
若出现极少量差异，先检查 GPU 与浮点设置是否与《运行说明》一致。

### A7 提交文件格式校验

```bash
python scripts/check_submission.py $AIC_ROOT/outputs/submission/pred_results.zip
```

**判据**：行数 37,444、文件名唯一、类别号落在 0..749、格式为 `文件名.jpg, 类别号`。

## 七、常见偏差与处置

| 现象 | 可能原因 | 处置 |
|---|---|---|
| 训练从头开始但逐轮读数整体偏低 | 分辨率不是 448 | 检查 `AIC_IMG_SIZE` |
| 留出集规模报 7,536 ≠ 7,537 而中止 | 清单枚举顺序差异 | 显式设置 `AIC_AUDIT_EXPECT_VAL=7536` |
| 推理耗时异常长 | 数据解码是瓶颈 | 提高 `--workers`（不影响结果）|
| 出现极少量类别差异 | 硬件浮点差异 | 重复一次；仍差异则记录数量与位置 |
| 类别分布明显偏斜 | 未执行校准步骤 | 确认 Sinkhorn 校准已运行且目标为均匀边缘 |
| 显存不足（路径 B） | batch 过大 | 保持 `batch=96`，或按显存等比下降并同步调整学习率 |

## 九、复现边界

1. 本方案不包含赛事数据；训练集与测试集需按官方渠道自行获取并置于约定目录。
2. 推理为确定性流程：视图随机裁剪按样本下标播种，与工作进程数无关，因此结果可逐行对齐。
3. 训练过程受硬件浮点与并行归约顺序影响，逐轮读数允许小幅偏差（见 B5 容差）。
4. 若需核对随附权重的完整性，以《权重校验》中记录的 MD5 为准。

## 附三、由实验得到的三条判据

1. **在训练域内提升分辨力的手段一般无效。** 增大容量、加强约束、更换损失形式、扩大微调范围，
   都属于这一类：它们能让模型在同分布的困难样本上更好，但这些样本并非线上真正卡住的那一批。

2. **不依赖模型分辨力、直接改变决策或优化几何的手段能够稳定兑现。**
   典型例子是类别均衡校准与优化器层的平坦化（SAM / SWA），它们不改变输入分布，因此不受域差影响。

3. **改变输入分布的手段必须对准测试域中真实存在的特征，方向错则有害。**
   测试图的成像质量与细节量是真实存在的差异，因此画质退化与分辨率覆盖有效；
   而"把输入钉死在训练域"或"覆盖测试域并不存在的质量档位"则一律变差。

## 附四、关于本地读数与线上读数不一致的说明

实验中出现过两个**本地读数与线上读数方向相反**的情形，一并记录，供复核者参考：

| 机制 | 本地读数 | 线上读数 | 说明 |
|---|---|---|---|
| 输入统一对齐到测试压缩质量 | +6.01 | −1.88 | 本地增益无法迁移 |
| SWA 窗口后移至 ep8–12 | +0.26 | −0.55 | 方向相反 |

对第二例我们有一个可检验的解释：**缩短平均窗口得到的是更"尖锐"的解**，
而**本地留出集与训练集同分布**，会奖励这种尖锐解；**测试集与训练集存在域差**，
更偏好由更长窗口平均出的平坦解。这提示：在存在域差的任务中，
**留出集读数不能作为所有类型改动的唯一裁决依据**，尤其对影响解平坦性的改动。
本方案中分辨率与 SWA 窗口两项超参的取值，均以后者为准。
