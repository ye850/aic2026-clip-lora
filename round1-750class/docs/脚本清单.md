# 脚本清单与用途对照

本清单由构建脚本从交付目录**自动生成并交叉核对**，确保"清单里有的文件目录里就有、
目录里有的文件清单里就收录"，不留遗漏。

核验规则：对每个文件都用**含路径的完整名**匹配（例如 `src/lora.py`），
而非仅文件名 —— 否则 `finetune_lora.py` 会让 `lora.py` 看起来"已收录"而漏掉。

---

## src/ —— 核心库（训练 / 验证 / 推理共用）

| 文件 | 用途 |
|---|---|
| `src/config.py` | 全局配置：路径、分辨率、类别数、随机种子、图像预处理常量 |
| `src/data.py` | 数据集与清单构建：训练/验证划分、退化增强、画质增强开关 |
| `src/extract.py` | 图像读取与预处理管线（短边缩放 + 中心裁剪 + 归一化），特征抽取 |
| `src/lora.py` | LoRA 注入与权重管理（低秩适配器挂载到指定线性层） |
| `src/noise.py` | 噪声标签鲁棒损失（SCE 等）与软目标自洽判据 |
| `src/finetune_lora.py` | 训练主程序：训练循环、EMA、SAM、SWA、蒸馏、逐轮评估与检查点 |
| `src/sam.py` | SAM 优化器（求平坦极小，推理阶段不参与） |
| `src/swa_lookahead.py` | SWA 权重滑动平均与 Lookahead 变体 |
| `src/vpt.py` | Visual Prompt Tuning（本方案未启用，保留以保证导入可解析） |
| `src/region_attention.py` | 区域自注意力适配器（本方案未启用，保留以保证导入可解析） |
| `src/asam.py` | SAM 的尺度自适应变体（本方案未启用，保留以保证导入可解析） |
| `src/train_head.py` | 仅训练分类头的低成本消融路线与先验估计（本方案未启用，保留以保证导入可解析） |
| `src/build_soft_conflicts.py` | 从官方数据生成冲突组清单 `dedup_soft_conflicts.json` |

## scripts/ —— 训练链与出包

| 文件 | 用途 |
|---|---|
| `scripts/arm_runner.py` | 实验臂入口：注入式调用训练主程序，统一参数传递 |
| `scripts/chain_opt.sh` | 训练 + 出包一体链：前置自证 → 训练 → 生效校验 → 15 视图出包 |
| `scripts/pseudo_label.py` | 教师软标签生成（仅在训练集上推理，产出 `probs_train.npy` 与索引） |
| `scripts/predict_tta.py` | 推理端 15 视图 TTA 与 power 融合，产出测试集概率与提交文件 |
| `scripts/calib_sinkhorn_apply.py` | Sinkhorn 类别均衡校准，把概率校准到均匀边缘后出包 |
| `scripts/tta_lora_eval.py` | 留出集多视图 TTA 评估（分层读数：全体 / 低相似子集） |
| `scripts/check_submission.py` | 提交文件校验（行数、文件名集合、类别范围、格式） |
| `scripts/_zip_class_check.py` | 类别分布自检（期望每类约 50 张，检查是否异常） |
| `scripts/dump_val_names.py` | 导出留出集名单（用于跨机口径对齐与复核） |
| `scripts/compare_lora_vs_frozen.py` | 冻结特征对比与常用评估工具集（被 `tta_lora_eval.py` 引用，**推理链必经**） |

## configs/ —— 配置产物

| 文件 | 用途 |
|---|---|
| `configs/dedup_soft_conflicts.json` | 文件级重复标签冲突组清单（1,877 组）；训练时按文件名匹配，路径为相对形式 |
| `configs/train_meta.json` | 类别元数据（750 个类名、类映射、训练集张数）；**推理链必需**，不含任何图像或文件名 |

## docs/ —— 说明文档

| 文件 | 用途 |
|---|---|
| `docs/权重来源与校验.md` | 底座权重来源、获取方式与校验步骤 |

## 代码与数据目录（根层）

| 文件 | 用途 |
|---|---|
| `运行说明.md` | 环境配置、目录约定、训练/验证/推理命令、关键超参、复现核对表 |
| `复现方案.md` | 逐步复现与核对手册：两条路径（仅推理 / 完整训练）+ 每步判据 + 偏差处置 |
| `requirements.txt` | 依赖清单（版本为实测值） |
| `脚本清单.md` | 本文件 |

## 未收录的脚本（有意排除）

研发过程中的探索性脚本（参数扫描、诊断探针、数据统计等，命名以 `_` 前缀为主）
不属于交付链路的组成部分，**未收录**，以保证交付件的可读性与可复现性。
其中被采纳的结论已固化进 `src/` 与 `scripts/` 的正式代码与注释中。

## 运行顺序

```
build_soft_conflicts.py   （可选：重建冲突组清单）
      ↓
pseudo_label.py           （可选：重建教师软标签）
      ↓
arm_runner.py / chain_opt.sh   （训练 → 生效自证 → 出包）
      ↓
tta_lora_eval.py          （留出集评估，核对读数）
      ↓
predict_tta.py → calib_sinkhorn_apply.py → check_submission.py   （提交文件）
```
