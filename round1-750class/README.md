# 复赛 · 750 类噪声标签细粒度分类

> **榜单最高 77.7241** ｜ 团队：明鉴
> 148,695 张训练图 / 750 类 / 标签噪声率约 33%

---

## 一、赛题特点

| 项 | 值 |
|---|---|
| 训练集 | **148,695 张 / 750 类**，类目录名为纯数字 |
| 标签噪声 | **约 33%**（同图被复制到多个类目录造成的冲突 + 标注错误）|
| 预训练权重 | 仅允许 OpenAI 官方 CLIP ViT-B/32 |
| 评测 | 只看 Top-1 Accuracy |

**噪声是这道题的全部难点。** 训练标签本身有错时，模型"学得太好"反而会把错标签记住——所以在含噪标签上算出来的验证准确率**不可信**，我们把它降级为"参考"，只以官方榜单为准。

## 二、方案

```
图像 448×448
   │
   ├─ CLIP ViT-B/32 视觉塔（官方权重，LoRA r=16 注入 q,k,v,out,fc1,fc2，解冻最后 4 层）
   │
   ├─ MLP 头（hidden=1024）+ 可学习温度
   │
   ├─ 损失：SCE = 0.1·CE + 0.05·RCE
   │         + 类平衡权重（逆频率）
   │         + 冲突组软目标（组内标签均分，组总权重=1）
   │
   └─ 推理：多视图 TTA → Sinkhorn 均衡校正 → 提交
```

| 超参 | 值 |
|---|---|
| 输入分辨率 | 448 |
| LoRA | r=16，`q,k,v,out,fc1,fc2`，`unfreeze_last=4` |
| 头 | MLP hidden=1024 |
| 优化 | lr 2e-4（头 ×5），batch 96，12 epoch |
| EMA | 0.999，用 EMA 权重 |
| 自划验证 | val_ratio 0.05 / per_class 8 ⇒ **7,536 张** |
| 权重元信息 | `best_ep=5`，`best_val_acc=0.774018` |

关键一点：**分类头的小时把算力花在方法迭代上**——冻结特征 + 轻头能在一轮内跑完几十个对照，比端到端重训换来的信息多得多。

## 三、这一阶段判死了什么

85 份实验记录里有多份**判死审计**，最典型的三类：

| 方向 | 判死依据 |
|---|---|
| **标签修正 / 带权标签修正** | 修正后的自划验证提升，但榜分不动甚至下降 |
| **域差归一化类改动** | 三类独立判据全部不通过（详见 `experiments/域差量化与三类独立判死_20261004.md`）|
| **筛样本 / 减训练集** | 非循环判据下不可行（`experiments/样本筛选可行性_非循环判据_20261004.md`）|

**还有一个反复出现的教训**写在 `experiments/更正_*.md` 里：同一个机制在**不同切分**上测出来的符号会相反。本项目栽过两次，之后定下规矩——**所有数字必须标注"测在什么切分上"**。

## 五、怎么跑

```bash
pip install -r requirements.txt

export AIC_DATA_DIR=/你的数据根        # train/<类>/、test/
export AIC_CLIP_DIR=/你的/CLIP/ViT-B-32

bash scripts/arm_runner.py --help      # 训练入口
python scripts/predict_tta.py --help   # 推理入口
```

> 训练权重未随仓库发布（用赛题数据训得，公开有边界问题）。有数据即可按 `docs/复现方案.md` 重训。
